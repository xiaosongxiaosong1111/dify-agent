# 运行诊断的实际执行与发布来源核对

0.38.0。相同应用／环境／Sierra修订不保证执行了当前代码；Dify可能已在相同App内重新发布或人工修改。诊断新增核心图来源证据，既有历史标记不直接当作当前方案。

先检查原运行记录的环境绑定、应用UUID、唯一workflow_run_id及当前业务修订。远端读取仍只访问原记录指向的应用。Dify1.17.1 `WorkflowRunDetailResponse.graph` 是该次执行快照；有可信核心图时，最多追加一次 `GET /console/api/apps/{原App}/workflows/publish`，读取当前已发布workflow ID和核心图，不能以编辑草稿或缓存替代。原运行详情没有workflow_id字段，本功能不编造执行版本ID，内容一致也不证明同一发布版本ID。

三方比对：实际执行核心图、当前已发布核心图、当前修订的Sierra成果核心图。对每个实际节点ID、parentId、data（仅去除selected界面状态）及连接端点／sourceHandle／targetHandle／data计算规范化SHA256，排序不改变连接含义。节点顶层位置、尺寸、视图不参与；data内其他字段仍保守参与，平台规范化或描述改动也可能判不同，需复核而非自动覆盖。未核对完整应用特性、资料真实性、外部资源或业务正确性。

结构／字节／递归上限、重复节点／连接、丢失引用、共享／循环结构、非有限数或不兼容字段均为未知，不拿部分图／节点ID列表猜执行版本。最多1500节点／连接、40000结构项、60深度、2MB核心摘要输入；本机成果读取限本任务目录和当前修订，并沿用无密钥／安全YAML规则。

只保存三份哈希、节点／连接计数、可信已发布workflow UUID、核对状态和说明，不保存实际图代码、输入、输出、环境秘密或任意发布响应。读取失败仍保留已采集节点证据，但不标当前；本地分析未做远端图核对也不能标当前。原运行和验收结论不改变，不重跑、不生成修复或调用模型。

当前来源必须身份快照匹配且三个核心图相符。采集期间当前App、成果指针／内容、环境或源运行变化则拒绝保存，不能把旧来源绑定新方案。其他Dify用户在采集后再发布无法由这一次读取持续证明；证据以采集时为准，使用建议前重新核对。旧诊断没有新字段时在界面明确要求重新读取，不改写历史数据。

原生Agent轨迹仍未适配，缺可信来源的旧记录仍只分析本地。测试与页面证据见development-status.md；本轮只有隔离受控远端响应，没有真实模型或Dify发布写入。
