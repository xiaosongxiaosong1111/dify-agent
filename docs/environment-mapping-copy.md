# 从已存映射创建独立本机任务

0.224，2026-10-19。仅原生 Agent 单包文本／受限知识集。不会创建、覆盖或运行 Dify 应用。

在目标映射完整预览并主动保存后，展开“基于已存映射创建独立本机任务”，读取本次复制范围。服务会重算来源修订、完整映射、目标上下文与保存版本，并列出不继承记录的准确数量。填写名称，分别确认“独立本机任务”和“复制范围”，再明确创建。

复制内容：八项需求文字、完整目标 DSL 和手动修改、目标模型配置、Agent 生成建议、原模拟与待验证条件。材料、测试样例、历史版本、运行记录及确认记录留在来源任务，不复制为新任务证据。需求中的原材料引用和旧资源方案文字不自动改写，必须在新任务重新核对。该有限范围要经用户勾选确认，不能悄悄省略。

来源任务、源配置、原引用及历史保持。新任务独立 ID／修订 1，原生 Agent 类型保持，需求与配置均待确认、准入开启，无产物／Dify 应用／运行或审批。完整手改 YAML 保存为 `mapping_draft` 本机引用；不是目标 Dify 实际草稿或实时源应用。必须分析并明确保留，再复核需求和配置，才能继续构建／导入流程。

Task、DSL 引用、创建回执一次事务保存；出错不留下半个目标任务。同一来源和创建标识的完全相同请求只返回同一个任务，不重复创建。标识相同但内容不同会拒绝。复制范围还绑定来源已有回执总数；创建后另一标识使用原范围会拒绝，需重新读取并明确核对已有结果后才能另建。

若回执中断，本页保留创建输入和同一标识，不自动重发。可点击“查询本次创建结果（只读）”；无记录或归属不符时不猜测成功。也可明确继续同一次创建，仍使用原标识。未知请求输入及标识只在本页暂存；已经创建的后台回执持久保存，刷新后可在“找回已创建的本机目标任务”只读列出并打开原任务，不需要重新创建映射预览。历史最多读取最新20条，损坏、失联及截断明确；更早历史尚无分页界面。尚未到达服务器、因此没有回执的请求，不能被历史冒充为成功。

开发者 API：

- `GET /api/tasks/{id}/environment-mapping/copy-scope`：只读范围、计数和摘要。
- `POST /api/tasks/{id}/environment-mapping/copy-task`：严格 `revision`、`draft_revision`、`preview_token`、`scope_token`、UUID v4 `operation_id`、`name`、两个布尔确认字段 `acknowledge_local_copy` / `acknowledge_scope`。不接受客户端任意 Task 或配置。
- `GET /api/tasks/{id}/environment-mapping/copies`：只读最新20条本来源历史，字段白名单，不含请求参数或DSL正文。
- `GET /api/tasks/{id}/environment-mapping/copies/{operation_id}`：只读查询相同来源的创建回执，不新建。
