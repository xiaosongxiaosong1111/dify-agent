# 字段表可选规则

0.179已实现的前端内容；实际部署及验证以development-status.md为准。

在现有平面字段表中，用户可展开每行可选规则。文字字段支持0—1000000的最小／最大Unicode字符数，以及每行一个的1—100项文字枚举；保留顺序及首尾空格，不删除重复、空行或自动改值。空字符串枚举及复杂规则仍使用完整Schema。选项与长度冲突、反向长度、负数／小数／指数／前导零长度均阻止预览。

number／integer字段支持包含端点的整数上下限，各最多300位；空白不添加约束。小数边界、金额精度、嵌套及数组规则继续使用完整Schema。反向上下限、额外空格、指数、小数、正号、负零、前导零或超位数拒绝，不转换或舍入。这个300位是当前字段表的编辑范围，不是假定后端完整Schema只能使用此范围。

数值边界以完整整数文字构造JSON；若超出浏览器安全整数，模型节点采用完整structured_output JSON文字，交已有手动保存入口后台无损解析，不把浏览器舍入后的投影存回计划。安全数值仍可直接作为对象候选，所有采用仍需用户明确操作、保存及重新确认。可保存大整数Schema不等于实际文件对象输出范围扩大；文件对象试跑整数仍只采纳±9007199254740991，超出需求须讨论文本等方案，不自动转换。

改变字段类型不清掉旧规则；不适用的已填约束继续显示可清空，并阻止预览，不能静默省略。已有完整Schema不可被表覆盖；其它节点、提示词、模型、边、终点及校验代码保持。没有默认约束、任务保存、模型调用或Dify操作。
