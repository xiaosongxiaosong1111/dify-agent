模型返回后即显示结果，配置状态刷新失败单独说明，不把真实调用成功变成失败；JSON 失败后也刷新后台能力状态。网络／权限／超时等错误在模型卡片内可见。两个探测只证明各自短调用，不自动证明工具、图片或完整规划能力。
