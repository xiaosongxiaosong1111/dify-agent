# 主弹窗的键盘操作（0.320）

新建任务、模型接入及编辑、Dify环境、登录、材料引用和执行规则使用的主弹窗，现在有模态语义及可访问名称。打开后焦点进入弹窗中的可用输入控件，Tab/Shift+Tab只在当前可用控件间循环；隐藏、禁用和关闭折叠区中的控件不会进入循环。内容动态变化时重新取得可用控件，不依赖打开时的固定列表。

弹窗打开期间，背景区域设置为 `inert`，避免键盘焦点走到背景任务或执行按钮。Escape只关闭主弹窗，不提交、确认、取消后台操作或请求模型；子控件已处理的按键和输入法组合过程会被尊重。关闭图标有明确名称，图标、底部关闭和Escape都会恢复有效的原入口焦点。列表切到编辑页时保留外部原入口，不把已移除的内部按钮当作返回目标。

关闭只恢复原来的背景inert状态；此前已禁用的背景不会被擅自激活。原入口已移除、隐藏或禁用时，不强行把焦点交给无效元素。没有弹窗时不拦截Tab/Escape，原业务保存和确认规则保持。关闭弹窗仍不意味着后台工作已取消，也不改变现有各表单关闭时的草稿保留行为。

先在旧版复现缺少dialog语义；修复后9项隔离浏览器检查通过：初始焦点/可访问名称、双向循环、背景隔离、Escape不保存、有效入口恢复、关闭图标/按钮、原inert保持、列表/编辑切换以及零写入。首轮末项使用了错误按钮名“添加模型”，改为界面实际的“添加”，原失败日志保留。流程图12项键盘/选择/结构回归及构建也通过，后台只修改版本号，没有跑全量。
