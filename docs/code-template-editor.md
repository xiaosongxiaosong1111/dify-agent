# 代码／模板编辑和诊断定位

0.47.0 在流程页加入代码／模板编辑卡，属于节点配置和运行诊断后的人工处理功能，不是新增 Dify 测试样例。

- 完整代码直接编辑，Python 3／JavaScript 语言声明显式选择；切换不翻译、不替换代码。
- 完整模板直接编辑，固定输出 output；输入绑定仍显式填写 JSON。
- 输入变量与代码输出声明可独立编辑。无法解析的 JSON 保留原文字，后台保存时拒绝，不回退旧配置。
- 支持顶层及单层迭代／循环的业务代码、模板。只改对应位置的字段，保留其他配置、连接及循环状态政策；编译器生成的保护节点不会暴露为可编辑业务节点。
- 来源匹配的当前诊断提供“查看节点配置”，支持代码、模板、HTTP、大模型、知识检索。按任务 ID／修订核对，流程读取完成后打开唯一对应配置卡；找不到或不唯一明确说明，不猜测其他节点。定位只读，不修改计划。
- 历史修订、其他应用、未核对执行／发布／成果来源的诊断不提供当前方案定位入口；有未存修改或其他活动时禁用入口。

所有编辑仅进入现有本机草稿。后台保存检查、修订变化、重新确认、构建和真实验证保持原规则。不是自动修复，不执行代码、渲染模板、派发模型或重新发布。

验证：前端构建、11 项受控页面检查通过并视觉核对。测试拦截全部写请求，只提供内存页面夹具，确认真实用户任务前后相同；没有新增 Dify 应用或模型／接口执行。后台逻辑未改，最近完整后台为 0.45.1 的 1301 项，0.46 诊断专项为 77 项，不重复完整后台套件。
