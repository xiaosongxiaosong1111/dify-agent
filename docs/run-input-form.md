# 按最终成果准备试跑输入

0.74.0 已部署。Workflow 自由试跑增加直接输入表单，固定验收样例仍只读；Chatflow／Agent 不借用本表单。

本机只读 GET /api/tasks/{id}/run-input-schema 在任务锁内读取当前修订成果，返回实际入口字段、修订、SHA256及 static_only 说明；没有读取模型、Dify或知识库。没有当前成果、未知类型、非法声明、重复变量或超过100个变量时整份表单拒绝，输入原文保持，不截断入口或沿用旧计划。仅投影入口配置，不返回整图、代码、运行输入输出。

界面读取／刷新不改输入；非对象或未完成JSON暂停表单。提供值的勾选仅主动添加或移除本次输入，不改入口定义。数字用JSON数值，空白仍未完成文字，不猜0；选项精确匹配，合法 __unset 等值不与占位碰撞。已配置默认值仅主动点击才填入，取消可选字段不会自动补默认。原生隐藏字段明确标识，未声明JSON字段不自动删除。

必填省略或null即拒绝；可选省略/null由原生使用已确认默认。本轮不证明实际Dify已发布入口与当前成果相同。表单修改不派发、不改变需求／配置／样例确认；输入仍经原试跑按钮、资源绑定、预算及最终成果输入检查。修订不同的迟到读取不呈现；读取失败不能清空原输入。组件键与报价面板隔离，避免输入更新时重复表单。

验证：8新增后台、81输入／API相关通过（6.20秒／既有Starlette提示1）；最近完整仍0.73的1811项通过，不虚增为本版本完整1819。前端主498.50kB／表单延迟4.39kB构建通过；7受控页面及视觉通过，所有写禁止、真实任务不变。没有新增实际模型调用、Dify应用或整图运行。
