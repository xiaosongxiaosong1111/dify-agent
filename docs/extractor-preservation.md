# 参数提取实际修改保留与范围7

0.63.0 将顶层文字参数提取接入当前实际 DSL 的读取、差异、合并、重新确认和构建。字段说明／必需规则／枚举、完整模型参数、指令、查询 selector、模式、标准有界 Chatflow 记忆和布局按用户当前文件保留，不重编译原文件。

原生文件没有 Sierra failure_policy 时，校验器只根据当前真实连接定位唯一直接接入的 IF 和成功 case，再检查成功标识为数字等于文字1、明确两个出口及业务字段只能在成功路径使用。缺保护、绕过／改成0／在失败或共同路径使用默认参数均拒绝；不插入新保护、移动节点或删除内容后宣称已保留。

模型／视觉／标准记忆检查沿用文字模型契约，允许 prompt、固定已声明类型、根层及单层容器明确DAG提取。工具模式、动态参数、图片、独立／无界记忆和嵌套容器提取未适配。任何不支持内容保持在原文件并说明条件，由用户补齐或缩小范围。

验收建议从最终文件取得真实 parameters（name/type/description/required/options）、query、instruction、reasoning_mode、model、memory 和 vision；实际 IF 条件及连接已经随整个图摘要提供。输入、预期和异常样例应覆盖抽取成功、缺字段和必要业务校验，不把节点成功或默认值当结果正确。

轻量验收建议发送范围升级 scope_version=7，加入提取字段、枚举、必需规则及状态检查等内容。旧6（以及旧5）启用路由未确认前阻止，不静默转主模型；每次正式建议仍由用户主动发起，历史费用保留，开发阶段不实际发送新业务资料。

12 项新增本机检查，包含两类型完整往返及失败保护拒绝；保留／分类／语义／路由64项专项通过，完整后台1637项通过，既有Starlette提示1。当前没有真实 Dify 资源写入或供应商调用，原用户任务不变。实际提取效果、真实文件联调、复杂嵌套和完整费用控制仍需后续验证。

0.76 内部成功检查依据原图边线核对后再投影循环；实际参数／指令／模型／布局保留，独立记忆拒绝。新的静态校验也阻止聚合直接使用未受成功分支保护的业务参数，不代表旧导入应用已经重新验收。
