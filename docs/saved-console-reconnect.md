# 使用已保存资料明确重新连接（0.252）

环境列表对已保存资料的连接提供“准备使用已保存资料重连”。准备只读本机并创建15分钟有效的方案，显示原URL、Dify版本、已固定工作空间和请求数量；用户另行勾选确认后才登录，不需要再填写邮箱密码。

- 仅原URL/版本/工作空间绑定完整、邮箱密码确实已加密保存的Dify1.17.1连接可准备。不得借旧凭据登录其他实例/空间；旧缺空间证明的资料不放行。
- 方案绑定环境身份、连接修订、暂停/诊断状态、加密凭据及加密文件指纹、此前已尝试记录。指纹来自随机密文，未保存明文密码摘要；公开响应不包含原绑定或指纹。
- 确认只有1次登录POST，登录内读取应用列表1次，再用临时新令牌读取工作空间身份1次；直接使用登录适配器，不经过自动续期/GET重试。空间不符、连接/资料在途改变、密文不可读都不提交旧登录结果。
- 新管理Token/CSRF与成功回执在一个SQLite事务提交；加密邮箱密码、运行Key/库Key/归档Key、任务确认/成果/App和连接修订保持。成功后恢复原连接的自动续接，不补发此前任何操作。
- 在途重连阻止同环境任务修改、环境替换及管理请求；保留只读快照的管理适配器也能识别该状态。忘记资料可中断后续提交；已派发的登录不能据此撤销。
- 失败单独留安全诊断并维持暂停；同方案不能重用，旧的其他准备方案也因最近尝试变化失效。服务重启只记未知并保留旧凭据，不登录、不重放。读记录只访问本机，并仅显示当前原目标的记录，其他目标旧记录仍保留。
- 登录失败或网络中断可能已在服务端创建会话；本机未成功提交新凭据不等于服务端没有收到登录。记录状态不代表平台资源或业务验收。
