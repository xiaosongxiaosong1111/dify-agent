# PDF/Word文字提取范围与部分内容

0.294修复T048/FR-05的两处实际缺口：PDF只要任一页有字就当作解析完成，未提取文字的其它页没有明确阻断；Word先收集所有段落再收集表格，表格会被移到末尾，嵌套表格还可能遗漏，合并单元格重复输出。

现在新上传PDF逐页提取一次并保留页码。每页都取得文字才作为本次页面文字提取成功；任何页无可读文字或提取失败，材料仍needs_input，正式正文为空，列出未读页。未提取文字可能是空白、扫描页或提取器限制，不据此断言页面内容。能读的部分保存在partial_text，界面仅提供带“覆盖未确认”标志的预览，不自动保存为完整正文，不绕过需求/引用门禁。用户可以核对后主动补充文字与范围，原PDF、原错误和历史保留；这是用户文字，不变成原文件/OCR成功。

可读PDF也保留文字覆盖说明：所有页有文字不代表图片、布局、OCR或全部业务含义已读取。加密PDF明确要求先在本机解除保护，此入口不接收密码；超过100页、损坏或无页文件维持待处理。10万字符上限保持，不为保存预览而截断超限内容。提取器异常不会把内部文件内容放进错误提示。

Word按主正文和单元格顺序读取段落、表格及嵌套表格；同一合并单元格只读一次。保留提取文字及顺序，不承诺版式还原。界面和后续来源摘要说明未读取页眉、页脚、脚注、文本框及图片；无正文或损坏文件不算解析成功。这里未新增OCR、图像语义或全部Word结构支持。

extraction_coverage保存限定格式、范围说明和PDF总页数/未读页；后续访谈/规划沿用范围说明。partial_text不是已解析来源正文，引用确认仍需成功解析或明确人工文字替代；不会自动采纳部分内容。人工替代使用其独立覆盖说明，原提取预览及未读页保存在历史。旧材料与确认记录不追改，需要明确重新上传才使用新规则。
