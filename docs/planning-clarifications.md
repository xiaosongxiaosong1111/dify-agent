# 规划暂停后，怎样继续

适用于 Sierra 0.200 的问题展示和 0.201 的报告保存。当前目标仍为 Dify 1.17.1／DSL 0.7.0。

模型返回“缺条件”时，Sierra 会暂停并保留这次调用的用量和费用估算，不把澄清当成有效计划，也不自动删功能或改选资源。右侧规划记录可展开问题，以及模型实际提供的建议、理由、体验变化、费用影响和人工工作；没有提供的说明不会自动补成事实。

1. 先核对“输入修订”。历史问题只供参考，不能作为当前方案的确认；当前问题也只是模型建议，尚未核实。
2. 如果不理解某个问题，点击“放入只读讨论框（尚未发送）”。它只准备输入文字并切换只读讨论，不发送、不调用模型、不修改任务。已有未发送文字会保留，请先发送、另存或清空，再放入问题。
3. 自己点击发送后，才会调用已配置的讨论模型并产生相应费用。只读讨论仅帮助理解；即使说“就这么做”，也不会更新需求或执行资源。
4. 决定以后，在需求检查模式或对应需求／配置区域明确填写选择，保存并检查新修订，再主动发起规划。继续遵守当前需求准入、范围、配置和资源确认，不沿用旧修订的批准。
5. 报告中的“规划澄清问题（未确认）”保留已保存的问题和所属修订，方便续接。它不是用户答案或验收结论；旧记录没有结构化问题时不会从原响应猜测补齐。

如果提示“响应不完整”，部分内容超出了可识别格式或大小，请同时查看有界的原响应预览。若原预览也注明截断，不能把它当完整方案。报告最多保存50份问题记录、总计256000 UTF8字节，并最多检查5000次规划记录；超限或元数据无效时明确不可用，不给部分清单冒充完整历史。原任务记录仍在，不会因此删除。

如果暂停原因是费用、时限、供应商错误或流程结构错误，应按对应诊断处理；问题清单不能解除这些限制。静态候选通过也不代表 Dify 已成功导入、试跑或业务验收。

本轮真实模型质量证据见[八场景结果](../work/semantic-acceptance-plan/summary.md)：冻结0.199，各一次，5个静态候选、1个无效文件图和2个澄清响应。0.200／0.201修复后的模型稳定性尚未重新付费验证。


## 保留的流程候选需要修改时（0.202）

若暂停记录已有完整计划对象，可点击“读取保留流程候选原文”，先查看后台已存对象的完整JSON，再主动“放入未保存流程草稿”。这是编辑起点，可能仍缺节点或有配置错误；读取和载入都不会修复、保存、确认或运行。完整JSON是后台对象的重新序列化，不是供应商响应逐字复原；未保存的小数原始词法不能恢复。

已有手动修改时，先处理这些修改；不要为了载入候选删除自己的内容。历史修订仅供查看。没有完整对象时，系统不会拿截断预览拼方案。载入后可用原“未确认流程草稿”保存编辑进度，修正后再“后台校验并保存计划”，重新确认配置并构建。浏览器对象预览可能舍入大整数，编辑应使用读取到的完整文字。

0.203起，流程样例工具条两列展示；已有未保存内容时按钮禁用，防止填入样例覆盖手改。需要保留编辑时，可先用“未确认流程草稿”保存副本，再主动收起原编辑；新样例同样只进入本地草稿，不是自动生成结果或运行通过。


## 先检查草稿，不急着保存（0.204）

进入流程页，填写或载入当前草稿后，点击“检查当前草稿（不保存）”。检查使用当前已保存的任务配置，因此先处理未保存的需求／配置编辑；流程JSON本身可保持未保存。它会展示支持范围内的结构、引用、缺节点和JSON行列问题，以及代码／平台未验证事项；不修复、不编译、不执行代码，也不调用大模型或Dify。

通过只表示这份计划结构通过，不能据此确认资源、宣称文件已解析或业务已跑通。编辑原文、切换任务或修订后，旧结果立即失效；需要主动重新检查。正式“后台校验并保存计划”仍独立重新检查，结果不会自动代替保存或确认。


## 明确补充一个漏掉的文档提取节点（0.205）

如果原稿恰好只有开始/结束两节点和一个必填单文件，连线与最终text输出却引用同一不存在节点，会展示补充建议。请先核对缺失ID、文件来源和“缺失或解析失败终止、空文字不自动拒绝”政策，勾选确认后准备；它不会调用模型或执行文件。展开完整建议，认可后再主动放入未保存草稿。其它原变量及连线保持，大整数使用完整文字传输。

这只解决明确的一处缺节点，不判断任务全部需求已覆盖，不提供OCR或保证解析格式与内容完整。多文件/可选文件/复杂图不会被简化为这条路径。改变原文或撤销确认会清除建议；后续仍需要保存计划、确认配置、构建、核对真实资源和独立试跑。


JSON语法检查给出行列时，可点“定位到 JSON 错误”回到当前编辑器选中附近字符；文件末尾可能只是光标，不会补字或保存。修改后须重新检查；无效或超出原文的位置不提供跳转。原生Agent的文本／知识骨架在已有未保存内容时禁用，请先留存或处理原编辑。


未发送文字及本次对话方式分别按任务在当前页面暂存；切回可继续编辑，发送成功只清对应任务的已发送文字。讨论／问题／欢迎建议只填空框，不覆盖原稿或改其模式；先发送、另存或清空再放入建议。这不是后台持久草稿，刷新或关闭前请另存，不写浏览器存储且不会自动发送。
