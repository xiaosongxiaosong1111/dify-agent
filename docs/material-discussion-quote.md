# 材料页引用到只读讨论草稿（0.328）

在已核对的材料文字页选择“核对当前页并放入只读讨论草稿”。界面先重新读取同一来源的当前页，核对Task修订/材料ID、完整字段指纹、码点范围、本页摘要及与当前显示文字完全一致，随后才尝试放入空讨论草稿。不会自动发送、采用材料、改需求或产生新的模型调用。

草稿用JSON文字列出Task/修订、材料ID、原保存文件摘要（未知为null）、来源与覆盖说明、字段、完整字段摘要、引用范围/本页摘要和原文。每次只引用当前最多4000码点页，不带其它页；原解析片段明确未确认，不当作已采用正文。没有重新核对或解析原件，浏览器只独立核对当前页。

已有未发送文字保持，不覆盖或追加；重核期间新输入优先，调用最新草稿状态。忙状态、来源变化和切换后的旧回执不放引用；源变409清旧页及查找命中，坏正文/摘要拒绝，保留上次已核对页。翻页/改查询清本页操作提示，已放入的讨论草稿不自动删除。刷新关闭前仍须另存未发送草稿，沿用原按Task本页暂存规则，不新增浏览器持久化。

后续只有用户明确发送才按原只读讨论路径调用模型及计费；引用或其中指令不是资源批准/业务事实已验证，不作为正式确认。用户以后改变任务修订时，旧引用仍带原修订/来源，不自动当成新来源证明。

新UI8/材料查找UI11、相关39后端及构建通过，未全量。覆盖当前页范围、原片段标签、已有草稿、新输入/切任务晚到、源变与坏正文，无聊天发送或后台业务写入。原16、账本密文主Key/消费124保护通过，真实模型/Dify0；非引用语义或客户验收。
