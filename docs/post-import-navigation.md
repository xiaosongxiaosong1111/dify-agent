# 导入后的下一步导航（0.276）

此前已有导入标识的任务会直接建议准备试跑，未提示中间的发布和运行Key核对。现在Workflow/Chatflow的“下一步建议”依次读取当前修订、环境、App和应用类型的本机事实：

1. 尚无匹配发布成功回执：前往运行页核对当前App发布状态。不能因为本机没有记录就推断平台未发布。
2. 发布结果未知、尚未返回或回执归属不匹配：先查看原发布记录，禁止直接重发。
3. 已有匹配发布回执：核对并登记当前App专属运行Key；已配对的不重复创建。
4. 已保存配对：准备样例并核对试跑条件。配对声明只说明本机保存了对应关系，不证明Key仍有效。
5. 已有当前App及类型的普通运行记录：直接核对结果和未覆盖场景，不要求为查看旧结果重新发布或绑定Key。未知发布仍优先核对。

建议只读取本机保存状态，不解密运行Key，不查询Dify，不写任务或预算，不授予执行许可。点击按钮只导航，各发布、Key及运行入口仍保留原确认。文件、定时、人审和Agent专用路径保持原行为；页面未保存编辑时仍暂停建议。

同一修订下发布或Key配对变化也会使旧建议失效。交付报告与导航共用同一份发布事实判定，旧Workflow缺省类型回执仍兼容，Chatflow须有明确匹配类型。
