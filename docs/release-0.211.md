## 当前能直接使用的改进

1. **切换任务保留未发送文字。** 在任务A写对话并选择“只读讨论”，切到B不会带入A的文字或模式，返回A可继续。自由试跑完整JSON也分别暂存。它们都只在当前页面内存保存，刷新或关闭前须另存，不等于后台持久进度；已保存任务和对话仍按原方式持久保存。
2. **建议不会覆盖输入。** 对话框已有文字时，需求问题、配置／验收讨论、参考DSL讨论及欢迎建议不会替换它，也不会改原模式。原生Agent的两个骨架按钮会保护未保存的计划编辑，主动保存手改仍单独操作。
3. **先检查，再定位JSON。** 流程页“检查当前草稿（不保存）”不调用模型或Dify。语法错误可点“定位到 JSON 错误”，回到编辑器选中附近字符；EOF可能只显示光标。编辑后旧结果失效，仍须正式保存并复核，结构通过不是业务通过。
4. **试跑不悄悄改输入。** 重复字段（包括转义后同名／嵌套）、超安全整数、溢出以及解析后改变数值的小数或非零下溢会明确暂停，原文保持。不代用户选择重复值、舍入或转为字符串。正常0.1、1.5000等同义写法可用；字段类型仍须符合当前成果。
5. **后端也检查线格式。** run、run-input-check、run-case-input-check在资源操作前独立检查不明确JSON；run必须使用正整数修订，不接受bool／文本修订或未知字段。后端原始整数字面量仍按Python整数解析，具体Schema限制和浏览器可传范围分别生效，不表示任意数值精度、平台或执行权限已保证。
6. **本机存储及时释放连接。** 正常提交／异常回滚后确定关闭SQLite连接，避免Windows仍等待垃圾回收才释放文件；未改数据库结构、原密文或密钥。
