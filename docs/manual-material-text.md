# 未解析材料的用户文字替代（0.91）

## 可用路线

图片、流程图、扫描PDF和未支持格式读取失败后，可以在该材料卡提供用户文字及覆盖／缺失范围。正文1—100000字、范围1—2000字，明确确认人工来源；不是识图或OCR处理。服务器按Task修订、材料SHA及当前本机原文件内容核对，来源变化／文件不可读／旧修订拒绝。仅needs_input可采用，已有解析正文不能覆盖，原文件与原解析错误／版本保持。

采用后产生新修订、清相关确认／成果与验证；可用于文字讨论的status为parsed，但source_kind=user_supplied_text、source_file_parsed=false、覆盖说明及原错误明确保存。引用程度仍由用户单独决定，原保留／严格复现不会变成借鉴。未覆盖部分不能靠人工来源确认算已理解或交付。

访谈和规划真实输入包含这些来源标记及范围，系统说明禁止声称原图／全部页已读或OCR成功。报告包含原材料文字来源；不发送原始二进制、不调用识图／OCR服务，不自动发模型、确认或构建。后续主动访谈／规划会把采纳文字作为材料发送给已配置模型，仍按既有费用与确认流程。
