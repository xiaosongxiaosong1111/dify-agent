# 本机最终成果输入检查（0.128，待部署）

Workflow输入表单增加“本机检查本次输入”，在派发前主动核对最终成果的已声明标量输入。支持现有text-input／paragraph／number／select规则：必填不以默认替代缺失；数字真正有限数值、不转换文字／布尔／空串；选项属于原options；文本长度受原声明限制；未知字段拒绝，不删除。

API POST /tasks/id/run-input-check绑定当前修订与用户已读取入口的source_sha256；检查前后重新读取最终成果入口，变化时409拒绝旧结果。最多2MB输入，有限JSON，验证错误不回显原值。结果只返回元数据及输入hash，不保存输入或检查记录，不改任务，不填默认，不执行模型、Dify或生成应用。输入hash用于对应输入，不作为匿名化保证。

前端明确显示“本机入口检查通过 · 尚未试跑”，修改输入、入口或修订立即隐藏旧结果；失败和不同归属响应在操作旁反馈，原JSON保持。非法JSON、未读取入口或固定样例只读场景不提供可用修改／检查按钮。

这是局部类型／声明检查，不证明已发布入口一致、可运行、资源就绪或业务通过；没有自动放行后续运行或改变旧通用runtime纯文字兼容行为。人工资源准备原已有完整必填／未知字段校验仍保持。复杂文件／数组等入口尚未适配时明确拒绝，不改变应用类型。
