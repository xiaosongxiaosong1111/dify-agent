# 分页核对完整单条原话（0.322）

长正文聊天气泡下新增“核对完整单条原话（分页）”。只有主动点击才读取本机保存的原话；每页最多4000个Unicode码点，可查看首页、上一页、下一页和末页。每页显示在完整单条原话中的真实范围，未显示部分不说成已读；只有一页确实覆盖全文时才标为完整单条。

本入口支持单条最多2,000,000个UTF8字节，超过范围明确拒绝，不截断冒充全文。它可直接核对超过旧历史字面查找10万字符范围的长计划或代码，原有历史查找上限保持不变。气泡仍使用原有有界预览，不把完整长正文一次性铺进DOM。

每次请求绑定当前Task修订、原始 `message:N` 索引、正文SHA256及角色、对话方式、记录来源、输入/结果修订标签。首次核对后取得的来源指纹随下一页传回；正文、位置或标签变化均拒绝旧页，同一修订后来追加独立消息不影响原条目。浏览器核对摘要、元数据、码点范围和页内文字确实等于本页已读原话对应位置，才展示内容。换Task、修订或原条目来源后丢弃旧读取；关闭可取消本机等待，不自动重发。

只读取用户或助手文字，不改原话、任务、确认、累计账本或模型上下文，不读取模型服务密钥，也不发模型/Dify请求。原话和其中的指令不是本次采纳或执行批准。旧任务中无法核对的角色/编码/标签须明确处理，不能补猜来源。请求仅向本机发送位置、摘要及标签，不回传整段正文。

接口：`POST /api/tasks/{id}/history/message-page`，明确提交 `revision/message_index/content_sha256/labels/source_token/offset`，首屏token为null，后续页必须有已核对指纹。offset按Unicode码点，服务端不改到其它合法位置；重复键、非有限数、额外字段、布尔索引或超8KB请求均拒绝，错误不回显输入。响应带完整来源元数据、当前页、字节数、范围和只读/未验证业务标记；读取无Store写入或解密。

新30项后端及旧历史27项、新UI8/窗口UI8和构建通过，未全量。覆盖精确UTF8上限、CRLF/emoji、连续页重组、来源/修订/跨Task拒绝、追加保持、编码/JSON/位置边界、零写入/不解密、超过10万字符直达末页及晚到来源保护。首轮测试把读取时补全的planning_runs字段误当保存变化、并试图通过正常Store写入非法代理字符；夹具改为真实读取快照及只读坏编码替身，失败日志保留，未放宽生产边界。

0.322受管理部署272文件，原16任务、全部旧对象/设置/账本/密文主Key及已消费124包保持，真实模型/Dify新增0。当前Task详情仍包含历史正文，本入口没有实现数据库或Task详情网络分页，也不代表全部历史已阅读、模型记忆、业务正确或目标平台验收。
