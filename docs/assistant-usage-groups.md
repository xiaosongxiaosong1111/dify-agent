# 助手历史用量分组

0.181已实现，实际部署和验证证据以development-status.md为准。

从预算卡主动读取用途、原服务ID、型号、价格快照和资料类别的历史分组，所有已登记调用都计入，包括旧修订、重试、失败和中断。历史资料类别未保存时保持未知，不查当前供应商设置推断旧角色／地址。价格变化保留不同分组，数字形式相同的单价归一后归为一组；不按当前价格重算。

金额分为按原记录用量的估算小计、人工账单登记小计、已知预留及未知计数，不把预留加入已知金额。小额十进制精确累计，未知不按0。输入／输出Token同义字段相等时只计一次，冲突或非法值计为缺失；不根据输入加输出猜供应商total，不使用流式部分用量冒充最终值。已知Token和耗时仅列小计及缺失次数。

服务返回正文不表示建议合法或业务通过。不同历史输入、任务难度和确认规则不一致，这不是同案例受控比较，不能据此声称节省Token、便宜或提高质量，不自动改路由。

GET /api/tasks/{id}/budget/usage-summary?revision=...只读并绑定任务修订，不需提供凭据，不改变账本或预算。超过5000条／100组、重复或缺少标识、未知费用状态或金额超出本批精确汇总范围时，只返回unavailable及具体限制，不选部分统计。前端验证来源、版本、计数与未验收标志；错误、任务切换、预算变化或迟到回执不能沿用旧数据。快照仅代表读取时的本机记录，后续调用／账单登记须再读取。

不包含Dify执行、建库、连接测试或账本起始点前记录，也不是供应商总账单或预算硬上限；不输出原提示词、输入、账单说明或密钥。


0.182可下载当前已读取的同一快照（含范围不完整的说明），不重新请求，只导出明确字段。未知额外字段不进入文件；项目报告追加相同安全汇总及任务／账本元信息。报告与JSON仍非受控质量比较或供应商账单，不关闭AT-25。
