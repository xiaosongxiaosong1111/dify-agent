# 循环配置卡（0.85）

流程页新增按需加载的循环状态、更新和停止编辑卡：最大轮数／连续无进展限制；1—12个状态名称／标量类型／常量或外部初值；每轮唯一同类型输出更新；本循环状态停止条件、and/or、文字／数值文本／实际布尔；进度字段／业务依据及明确失败政策。分组展开，完整JSON可用。

输入0、false、空文字和未完成内容分别保持。数值常量仅明确有限JSON数字，0.及0x10保持原文，不自动变为0或16。切换状态类型、初值来源、重命名／删除，仅改用户操作字段，不同步其他引用或伪造更新；后台会解释悬空、缺失、错误类型。空白新增行不猜类型／初值／条件；超过简易上限或非数组不截断原值。

外部初值仅列类型一致、父容器全路径可用来源；正文更新仅列在唯一共同终点必经的同类型输出，提取业务参数需要成功门。后台仍为最终权威，候选不证明业务规则、执行质量或源资源可用。修改不保存／确认／构建／执行，原保护政策和正文连线不会重建。
