# 参考材料的借鉴、指定保留与流程核心复现

对应FR-07和交付清单06，开发任务344。DeepSeek实施，Codex制定范围、独立验收及反馈返工。

## 正常操作

在需求页“整理参考 DSL”上传无密钥的同类型参考文件，先看节点、连接和限制，再主动选择参考方式。上传、预览和加入材料均不调用模型或Dify，不会覆盖当前流程计划。

- 借鉴思路：沿用原有能力，按当前需求重新规划，不承诺保留参考的节点或图。
- 保留指定部分：写清保留范围，再勾选根代码节点或模板转换节点。后续自动规划须提供选中节点的完整配置，并由程序精确比较；手工保存完整流程计划也可核对。只锁所选节点完整配置，不锁连线或其它节点，不代表其余业务规则已经复核。
- 严格复现流程核心：当前支持无容器、编译器能完整表达的Workflow/Chatflow根图。节点配置、连接、features、环境/会话/RAG变量及插件依赖必须一致；画布位置和应用名称/图标不计入流程核心。不能表达的图明确拒绝，不能删掉节点后声称复现成功。

加入后，可在单份材料的“设置引用方式”入口重新选择保留节点。修改会产生新修订，使相关确认和成果失效。保留方式内未传选择字段的旧API客户端会保留已选项，显式空数组则清除；离开保留方式也会清除。批量变更方式或保留说明后，原选择会清空并提示逐份重新核对，不能把旧选择当作新声明。

## 当前边界

保留选择仅支持根code/template-transform节点。严格复现允许根start/code/template-transform/llm/knowledge-retrieval/if-else/question-classifier/parameter-extractor/list-operator/variable-aggregator/document-extractor/end/answer；参数仍须编译后完全一致。容器、循环/迭代、定时、人工审核、原生Agent和未知关键结构不在本批保证范围。

普通文字或仅写保留说明而未选择节点，可以保存继续讨论，不能据此自动规划或构建。实际DSL往返的人工修改保留与材料级保留/复现暂不能组合，须明确选择路线。原文件归属与SHA256在使用前重核；模型策略上下文超过24000 UTF-8字节时阻止自动规划，不截断冒充完整，可改为手工完整计划。

配置确认、模型候选准入和最终构建都会重新核对。检查失败不会静默改为借鉴，也不生成成功成果。成功静态报告位于artifact.validation.reference_preservation，始终标明business_verified=false、platform_verified=false；真实资源可用性、导入和运行另验。
