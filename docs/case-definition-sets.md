# 样例定义集JSON导入与导出（0.333）

运行页的“样例定义集”可下载当前后台已保存的定义，或选择一份JSON文件只读预览。下载不包含本页未保存稿、旧样例ID、运行成绩、确认、环境或资源许可。浏览器核对本次Task/修订和下载字节摘要；定义包只包含schema_version=1、当前app_type及cases。

文件为UTF8（支持UTF8 BOM）、1—512000字节、1—20例。类型须与当前Workflow/Chatflow/原生Agent一致，不自动换类型。每例明确name、input、required布尔值、expectation，可有当前类型支持的followups；输入/严格等值值保留原JSON类型。每例名称1—200码点，关键词/字段规则用非空列表、Schema用完整JSON原文、人工规则只含模式及判断标准。编辑器不能完整往返的旧字符串关键词、对象Schema、额外字段或首尾/换行语义会明确拒绝，不转换后装作原定义。旧接口/编辑方式保持。

预览拒绝重复/转义同名键、非有限/舍入/下溢、不安全整数、错格式/类型/超限、旧ID/成绩/确认或未知字段；不带会话接续与已上传文件身份，文件样例仍用专用入口。结构/编码未完整检查或疑似凭据也拒绝，原Task和文件不改，不回显私有值。文件名/字节/摘要及本次nonce/Task修订核对；摘要只证明本次文件字节，不证明作者或业务正确。

预览默认不选。明确选择并复核后，只为所选定义分配新ID并追加到本页未保存样例；已有未保存稿不覆盖，未选项不加入，双击不重复。草稿/任务/类型改变时旧预览失效，坏摘要/来源不生成追加入口。仍须原“保存验收样例”动作才写一次新修订，使需求/配置等按原规则重新核对，不自动保存、确认或试跑，不继承旧成绩。

本批没有把原JSON归档成材料，来源请保留原文件；关闭刷新沿原本页草稿规则处理。导出后台现存定义可能因旧记录超范围/不能完整往返而拒绝，不截断导出部分。512KB和20例是本批定义包边界，不改变旧Task/API能力或运行预算，也不证明当前成果支持所有输入或业务正确。
