# 本页未保存输入的离开提示

任务未保存编辑、任一任务的未发送对话/自由试跑输入或执行规则原文未处理时，刷新或关闭会请求浏览器原生离开确认；取消刷新保留输入。正常保存、清空或恢复原值后解除，另一任务的草稿仍受保护。

此提示不自动保存或发送，不把对话、试跑输入或凭据写入浏览器存储；用户明确离开仍按现有本页暂存范围丢弃。切换任务不清其它任务的未发送文字或自由输入，离开检查涵盖这些暂存内容，而不只看当前任务。规则是否仍待处理按原文与最近接受值比较，不因一次编辑后恢复原值仍拦截。

覆盖已有任务编辑dirty标记、页内对话/自由试跑输入和执行规则。不是所有独立弹窗字段的恢复机制，也不保证未交互页面、浏览器崩溃、系统终止或移动端强退能提示；原生提示文字和是否显示由浏览器决定，重要内容仍需保存或另存。不阻止页内切换，也不取消已派发后台操作。
