# Word材料的压缩包处理范围

0.306在调用Word解析库前，只读包目录核对处理范围：单部件展开大小最多32MiB、所有部件累计最多64MiB、目录项最多2048（包含目录项）。等于上限允许继续。这些是本机处理边界，上传原文件20MB和正文10万字限制仍分别保留。

此前20MB只约束压缩后的上传字节，Word库会在检查正文长度前载入关联部件；一个公开合成Word含33MiB关联二进制，压缩后小于20MB，旧版实际返回parsed。现在超限时不调用Word解析器，不静默跳过部件或截断正文；材料为needs_input、正文空，原文件/摘要保留，可拆分或精简后重传，或明确提供人工替代文字并保留原解析错误。未处理材料不进入模型材料来源，不能借引用方式绕过需求确认。

预检不解压条目到磁盘、不执行文件、不读取或展示包内文件名与原文；它检查目录记录的展开大小，不证明文档内容正确，也不是解析进程的CPU/内存硬配额或全部文件安全保证。通过后仍按原库提取正文/表格/嵌套，页眉/图片等原覆盖边界不变。旧材料和历史不追写，不自动删除大部件。
