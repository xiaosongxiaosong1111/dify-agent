# 本机资料重复与版本线索

0.295在参考材料区新增“检查资料重复与版本线索（仅本机）”。主动点击后检查当前保存修订，打开页面和刷新不会自动检查；材料或编辑状态变化使旧结果失效，需要再次主动读取。检查只读，不写任务、文件、预算或确认，不读取凭据或调用模型/Dify。

三类结果独立展示：原文件保存摘要相同、当前已解析正文逐字相同、同名但原摘要不同。正文比较不将JSON/YAML解析值重新序列化，所以格式不同而含义近似的资料不会冒充逐字相同。人工文字与人工核对图像正文标记独立来源，不将正文相同当原文件相同。未解析材料/部分PDF预览不纳入已解析正文比较；缺少有效原摘要时不判原文件重复。

原摘要来自上传时保存记录，不重新读取磁盘原文件；结果是技术线索，不是文件完整性复核。只检查前100份并明确总数/截断，隐藏部分不能当已排除重复。文件同名仅表示版本待核对，不按日期选择正确版本。不会自动删资料、替换文件、去重上传、选择最新版本或裁定业务事实。

已有需求分歧记录的待处理数量和来源失效状态单独显示，不将重复线索当业务矛盾，也不将“暂无重复”当已经检查全部冲突。具体事实仍在需求分歧工作台明确选择。接口GET /api/tasks/{id}/material-review需当前revision，回应禁缓存，返回限定元数据/分组，不回显正文、部分预览或原解析异常。
