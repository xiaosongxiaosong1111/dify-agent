# 文件流程起步模板

0.154在“流程”页新增“文件流程起步”。只适用于空白Workflow：先明确选择类型，再点击“填入文件流程草稿”。没有默认选项，不自动生成或选择模型。

| 类型 | 准备的草稿 | 需要复核 |
| --- | --- | --- |
| TXT单文件 | 必填document→原生文字提取→结束text | 文件与解析失败行为 |
| TXT文件列表 | 必填document列表→逐文件提取→结束文字数组 | 示例最多5个、顺序与重复、空数组与任一失败停止整批 |
| TXT文档问答 | 必填document＋question→提取→一个文字LLM→结束text | 任务模型、提示词、无资料依据时的回答规则、出站与费用 |

数量5和问题长度2000是未确认示例，可在现有节点编辑器里按实际需求调整，并通过后台检查。问答模板不包含模型Provider／型号／参数，编译时沿用用户在任务配置中选定的完整模型设置，不自动挑选替代模型。提示词及“资料未提供的信息明确说明”也是待确认建议，不当作已同意的业务规则。

填入只改变浏览器中的未保存流程草稿，节点、变量和连接可继续编辑。它不保存正式计划、不确认需求或配置、仅在本机准备，不调用模型、不创建Dify资源。仍须完成需求准入，核对并保存计划和配置，再生成DSL；运行另走具体资源与数据流批准。

当前已有非空编辑内容、已保存流程、成果、导入应用或源DSL时，模板入口禁用，不覆盖原内容；可继续编辑现有流程或另建空白Workflow。未保存的需求／配置或正在处理的操作也会阻止填入。Chatflow／Agent不显示此Workflow入口，不改变用户选择的应用类型。

三份浏览器实际生成草稿已通过原生DSL编译、保留检查及0.153文件试跑范围检查，输入计划保持原值；10项界面检查覆盖不自动填入、不覆盖手改／正式计划／源DSL／成果、没有自动模型或平台操作。全部是隔离与静态证据，未真实执行文件或模型，不能当作业务验收。

0.154主体为前端功能，后台仅更新版本号；没有重复完整后台回归，最近完整为0.153的3210通过254.63秒。实际构建及部署见development-status.md。


## 0.155 多个TXT明确拼接后交给模型

第四个选项需要用户明确选择格式（原文字分隔／编号分段）、实际分隔符、最大文件数1—20、UTF-8结果上限1—64000字节、空列表停止／空文字继续、单份空文字停止／保留位置。没有默认政策；可主动使用两个换行作示例分隔符。字面反斜杠n不转换为换行，界面用JSON转义展示精确值。无效数值不舍入、截断或改成默认。

点击准备只向本机 `POST /api/tasks/{id}/file-join-template` 提交当前revision和政策，返回五节点未保存IR及规范代码，不写Task、独立资源记录或密钥、不联网、不调用模型。后台拒绝已有流程／成果／App／源DSL、错误类型或修订；浏览器还保护未保存草稿及并发编辑。模型不自动代选，模板提示词仍待业务确认。

提取数组按原顺序、重复项及空白保留，编号采用 `### 文档 {序号}` 加换行；字节上限包含编号和所有分隔符，超限抛错，不把截断内容送模型。它不是token／费用／上下文上限，编号不证明出处，也不证明提取器完整读取所有原文。仅规范代码、输入绑定、类型／输出和唯一前置路径原样匹配才承认这套保护；不执行用户代码来验证。手改或自定义代码保留原值并明确拒绝按原保护试跑。0.156提供下述专用政策编辑器，不能仅改注释或手改常量后沿用保护。

15项创建界面隔离检查覆盖显式选项、严格数字、五节点草稿、不符回执拒绝及延迟回执不覆盖人工编辑；四份浏览器实际草稿均通过原生编译、保留与数据流范围检查。以上均未调用真实Dify或模型，完整结果以development-status.md为准。


## 0.156 调整已有拼接政策

“流程→调整已有TXT拼接政策”：明确选择根拼接节点，主动读取当前规范政策。编辑表单以已核对的原政策开始，不自动产生变更。选择新的完整规则后先点击“预览拼接政策变更”，查看原／新政策、完整候选代码及更新范围，再主动采纳到未保存草稿。

只更新原样规范模板。文件数改变时同步更新原开始变量max_length，预览明确说明旧值、新值及两个节点；其他政策只更新代码一个节点。节点ID、人工标题、提示词／模型、输入输出绑定、所有连接和其他字段不变。后台全草稿校验，浏览器再次拒绝政策以外变更。手改代码、绑定／数量不一致及未知模板保留原值并拒绝刷新；不自动修复。准备期间继续编辑、切任务／修订、换节点等使旧回执失效。

两个本机接口 `POST /api/tasks/{id}/file-join-policy/inspect` 与 `.../preview` 绑定revision、完整当前IR、node_id、request_nonce；preview另外带policy。只读与预览均不写Task／资源／密钥、不解密、不执行代码、模型或Dify。新旧草稿SHA256及随机标识核对；请求严格拒绝重复键、非有限数和超大正文，错误不回显请求值。最大完整IR为2MB、请求为2.8MB。

采纳后仍须保存、重新确认配置和生成新DSL，原成果、上传和试跑批准不会自动刷新或继续沿用。该编辑器不会把静态结果当作真实平台／客户验收。


## 0.157 明确文件后缀范围

四种起步流程均可明确选择TXT、MD、CSV、JSON、YAML、YML的非空子集；原TXT示例保留，其他后缀不自动开启。用户所选范围原样进入custom文件声明；多文件拼接请求也携带extensions核对，不匹配的回执不采用。不同格式的解析转换与保真限制见[file-formats.md](file-formats.md)，不能把上传成功、源哈希或生成DSL当作原文完整提取证明。
