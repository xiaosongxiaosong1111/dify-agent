# 已发送请求的未知结果

已发送Dify导入/运行请求发生读写中断、远端协议断开或成功HTTP返回不可解析JSON时，保留为结果未知并阻止同修订盲目重复；不再误记为确定失败。DifyError提供明确未知标记，记录附来源代码，状态不再只依赖中文文案。

只有非GET/HEAD/OPTIONS请求的ReadError、WriteError、RemoteProtocolError或不可解析JSON响应新增该标记；超时保留原有保守边界。连接建立失败保持普通失败，只读错误不标成未知写入。已知平台failed/stopped/partial-succeeded仍failed，非终态仍unknown并保留结果；204正常无内容保持原契约。标记不宣称写入成功，只说明不能排除远端已执行。

记录outcome_unknown及可用error_code，结构化未知不要求特定中文句子；兼容旧适配器含“结果可能未知”的错误。错误不回显传输消息或无效响应正文。原方案、成果字节、App绑定、输入及确认不改变，不做自动重试/重新认证重发，也不改判旧unknown或返还费用。此项不概括所有业务响应格式或HTTP状态的不确定性分类。
