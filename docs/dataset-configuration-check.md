# 指定目标知识库目录与索引计数核对

0.229，2026-10-19。映射界面填入全部目标库 ID 后，可主动选择管理连接或知识库 Key，点击核对。只读目录元数据，不读取文档全文，不执行检索、索引或模型调用，不更改任务或知识库。

最多 3 页、每页 100 条；找到全部指定 ID 就停止，不继续扫描无关库。只返回选定 ID 的字段，其他库的名称不会进入回执。缺权限不会自动切换凭据；超时、目录不兼容、翻页无新增 ID、同 ID 信息冲突或连接变化会停止，后页失败不会把前页当作整体成功。

结果区分：

- 文档／可用文档为明确、安全的非负整数，且数量一致；这仍不是检索通过。
- 空库、尚无可用索引、部分索引、计数缺失或矛盾，各自说明，不把未知当 0。
- 高质量索引缺少 Embedding 型号或供应商时保留缺口；有标识不证明其仍可用。经济索引不要求 Embedding。
- 可访问目录已结束仍未提供 ID：可能不存在或不可见，不推断已删除。
- 达到窗口上限还未找到：只是尚未核对，不能据此说库不存在。目录完整与指定 ID 核对完整分别显示。

名称或 ID 相同不证明资料等价。可用文档计数也不证明代表性问题、资料覆盖、权限、插件、Embedding 当前可用性、查询费用或客户业务效果。全部 `target_resources_verified` / `platform_verified` / `business_verified` / `retrieval_tested` / `task_modified` 保持 false，`model_calls=0`；不会删库、换库、补默认索引或把待验证成果升级为交付通过。

API：`POST /api/environments/{id}/dataset-configuration-check`，严格字段 `dataset_ids`（1—100 个明确且不重复的小写 UUID）、`source`（console/service）、`max_pages`（1—3 的整数）及 `expected_connection_revision`。回执绑定环境、连接修订、完整 ID 顺序、认证方式和页数范围；前端拒绝错误摘要与多余／缺失 ID，读取失败撤下旧结果并保留所有映射输入。

55 项直接检查和 141 项相关检查通过（有重叠，不能相加当独立数）；9 项纯展示、48 项源资源及 48 项部署静态资源界面隔离检查、TypeScript/build 通过。原 11 任务、密文、密钥保持；实际未请求真实 Dify、检索或付费模型，不能把合成回执算作平台／业务验收。最近完整后端回归为 0.226 的 4717 项。

## 0.231 异常处理建议

每个目录异常返回三个尚未执行的选择，说明体验、潜在费用、人工工作。用户可补条件、明确另选目标库、或保留待验证；无按钮自动修复索引或默认换库，计数一致不添加异常建议。处理建议是解释信息，不是资源批准，也不改变映射/任务。旧无建议回执兼容，结构损坏拒绝采用并保留输入。

40项模块、15项组件/合同、23源和23部署静态资源界面检查通过；未请求真实知识库或模型。
