# 会话计数更新（0.109）

Chatflow根状态赋值v2可在覆盖之外选择 `+=`、`-=`、`*=`、`/=`，仅作用于已声明number状态，来源须明确constant。例如初始count=0、每轮count += 1；这表示更新当前会话计数，不是每轮重置初值。用户须明确选择操作、数值与业务上限。不会自动添加节点或改连线。

常量为真正有限JSON数值，绝对值<=10^12；布尔、文字数字、数组、未知操作、变量算术以及除零（包括-0.0）拒绝。切目标／操作／来源保留旧值，不猜测转换或重置。string／boolean继续支持同类型覆盖。

原生数值类型float；静态初始值与常量限制不约束动态运行结果，不保证整数或金额精度、溢出处理或业务上限。需设计实际阈值分支及验收样例；当前没有执行真实多轮状态更新。不提供容器赋值或多个竞争写节点，原单写、无隐式根并行、项间自读写限制保留。

生成及手改保留维持原操作、值、UUID、默认值、说明和布局。验收建议最终DSL语义包含这些规则；轻量数据范围升为14，旧13须新确认，不发送运行中状态。任何真实模型调用和Dify应用／状态写仍须独立具体授权。
