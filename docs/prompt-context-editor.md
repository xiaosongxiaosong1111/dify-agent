# 提示词与知识上下文编辑

0.49.0 流程页支持直接编辑顶层及单层迭代／循环 LLM 的 system／user 提示词和 context_variable_selector。所有操作仅进入草稿，不调用模型、不读取知识库、不发布或重跑；后台保存、修订、确认、构建和验证门禁保持。

上下文开关不会自动选库，启用后先创建两个待填字段。候选仅列当前根图中所有路径上游的知识检索节点；内部 LLM 以父容器的上游路径为准。孤立、循环或无法可靠核对的草稿不提供猜测候选。候选基于草稿连接，不表示知识库可用、检索有结果或已真实验证；手填 selector 原样保持，保存由后台检查来源及路径。

按固定 Dify 1.17.1 源码，知识上下文提示词引用为 `{{#context#}}`。启用绑定但无引用、已有引用但未绑定，均明确提醒，不自动改写。用户点击“在系统提示词末尾加入上下文引用”才追加一个宏，保留原规则，已有宏时禁用重复追加。关闭上下文仅移除 selector，不删除提示词中的宏；需要用户决定如何调整。

无效 JSON selector 保留原文字，不沿用旧值；不是文字的提示词保持原始草稿并提示后台拒绝。这里不承诺处理完整图片／工具／多角色／Jinja2 提示词模式，仍按已有文字 IR 契约。

运行诊断跳转区分 LLM 提示词与模型两张卡：引用等一般错误定位提示词，凭据／额度定位模型配置。按当前任务／修订及已有来源保护定位，不因同一节点有两张卡而误认成多个节点；只打开配置，不执行修复或改变模型。

验证：前端构建、12 项受控页面及视觉核对通过。全部写请求禁止，模型／检索目录替身化，实际用户任务前后相同；没有新增真实模型、知识检索、HTTP 或 Dify 操作。后台逻辑未改，最新完整后台仍为 0.48.0 的 1348 项，不重复完整检查。
