# 规划只读规则工具设计（0.318首批实现，默认关闭）

T042/FR-24/FR-45：当前规划器已有确定性的`node_guidance`上下文，模型不能主动调用工具；现有工具探测只观察单次请求，不执行。首批新增明确可选的主动规则查询，保留默认路线，不以新入口冒充任意Agent工具能力。

仅Workflow/Chatflow生成完整计划，固定当前主模型、当前工具请求验证、OpenAI兼容协议和范围版本1；默认关闭。用户独立接受原上下文与固定公共规则/例子的最多两次模型请求及共享轮次/累计预算。全局修复上限为0、工具能力未观察/已失效、模型/价格/声明目标版本或规则库变化时不启用或派发。

只注册`sierra_lookup_node_rules`：参数只能为1—4个不重复的已适配节点类型（检索/条件/Python/文字LLM），当前应用类型和Dify 1.17.1由程序绑定。纯调用既有`node_guidance.lookup`，无任意路径/URL/文件/数据库内容/代码执行/网络/资源写入；完整结果最多32KB，超限停止不截断。示例占位资源不是当前配置、用户批准或运行证明。

最多两次模型HTTP、一次本机查询，各最多请求6000输出tokens/120秒，共用一次规划总时间/费用和TaskBudget。第一请求可直接返回计划（只1次），或返回唯一已注册工具请求；必须名称/单调用/参数/来源/用量可核对才执行纯查询，再把真实结果按tool角色回注固定主模型一次。第二次不再注册工具，不循环或修复，不换模型；未知用量、非法请求、暂停/旧修订/来源或预算失效均停，旧记录不重放。

独立协议适配器只服务新工具路线，原`call_model`和普通流式/图像/建议不变；TaskBudget增加受限内部stage，计价含工具schema和工具历史元数据，不用普通正文长度漏算。解析失败/截断/拒绝不回显供应商正文或凭据，未知费用保留。只读工具没有被程序调用时，不因模型口述而标记执行成功。

本机回执记录实际工具名称、查询类型、规则条目ID/摘要、版本/字节摘要、是否只读及请求准备/响应状态；仅保存实际完成结果，不能据模型说“已查询”补造。模型结果仍用原静态校验、手改保留、候选复核/确认及资源门禁；不自动执行Dify或把工具内容当新需求批准。重启只把在途工具/模型标为中断或未知，不继续查询/回注。

验收：真实HTTPX替身线格式含工具schema、assistant/tool配对及结果；无工具直接答1次、有工具2次且只1次本机查询；错误/多工具/额外参数/跨类型/版本/未知用量及共享时间费用/源变/暂停/取消/重启不续派；原路由/文本/图像/流式/预算行为定向回归。UI独立保存零调用、只读回执不伪造/不自动采用，原16及密文/账本保持。无真实Sierra/Dify新请求；另有用户再次要求委派的新Claude Code文档审查CLI失败，报告估算0、内部请求/账单未知，不算有效审查，不重试。
