# 保留候选的单处布尔格式预览（0.269）

第84批实际候选把布尔条件右值写成JSON字符串 `"true"`，严格校验拒绝。第86批通过独立人工副本验证仅改这一处类型即可形成有效图。0.269把这项人工操作接到保留候选界面，不额外调用模型。

在暂停的规划记录中主动读取候选原文，点击“预览单处布尔格式修正（仅本机）”，核对路径、原字符串和新布尔值，再点击“将此格式修正放入未保存草稿”。此时正式方案和原候选均未改变；后续仍走原有“后台校验并保存计划”、配置确认与静态构建。明确保存后来源为 `manual`，原失败记录保持。

仅支持当前修订的Workflow/Chatflow完整保留候选，且根条件中恰有一处声明为boolean、比较符为is/is not、右值精确为字符串true/false。原图的全部错误必须只有该类型错误，修正副本必须通过完整静态校验。多处、混合图错误、未知变量类型、历史修订或执行中任务均拒绝，不猜测其他修正。

本机GET `/api/tasks/{task}/planning/{run}/boolean-format-preview?revision=...` 返回精确差异、完整副本和摘要。明确载入前的POST `.../compose` 按修订及 `review_token` 重新读取和校验；token绑定任务、应用类型、候选、原方案和当前输入。两个接口均不写Store、不改确认、不收费、不请求Dify。前端核对归属、类型、字节与摘要，编辑中停用；切换任务后丢弃迟到响应。

验证：60项相关定向测试通过，另补的Chatflow正向用例通过；前端构建、实际84候选的API回放、12项隔离界面检查、6项真实本机API完整界面操作均通过。完整操作从预览到明确保存/确认/静态下载，在临时Store内执行，之后清理；无模型/Dify调用。生产只读界面6项通过，0.269部署前后全部15任务、对象、密文、主Key和旧回执相等，运行源码与快照匹配。[可审查结果](retained-boolean-format-preview-result-20261024.json)。

静态校验不证明代码运行、检索异常传播、业务语义或平台验收；这项预览也不把第84原模型失败变为成功。第91人工修正图已有独立平台两例成功，保持其原有范围，不据此扩大新预览或一般模型的保证。
