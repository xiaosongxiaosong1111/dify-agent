# 参考DSL的新节点识别（0.72）

参考材料摘要已识别问题分类、参数提取、标量数组处理及文档文件提取；不再把已适配类型笼统标为“未适配节点”。识别类型只说明有对应子集，不能替代字段、作用域、资源、版本、业务和实际执行检查。

摘要保留实际分类类别／指令／来源、提取参数／模式／来源、数组筛选／排序／提取／截取、文档来源／数组标记等字段。沿用1600字符的逐字段摘录上限与明确截断标识；完整内容仍在源文件，不能靠截断摘要宣称严格复现。文字分类及参数提取的模型依赖与LLM一并列出，避免后续配置漏选模型。

逐类型说明明确首项回退的范围、提取成功检查、数组真实操作顺序及空值、文档文件数组／扫描件／解析服务等限制。旧HTTP、迭代、循环保留说明同步到当前受限支持范围，不能反复告诉用户已实现部分仍完全不支持；嵌套、任意工具及未适配设置的缺口仍保留。

预览只读，不获取资源或调用模型；明确采纳为借鉴材料后才保存任务新修订，类型不变、需求重新确认、尚未导入。开发验证使用隔离DSL、已生成原文件和模型请求禁止替身；没有实际客户数据出站、新Dify应用或付费调用。轻量验收建议来源仍为当前计划或最终保留语义，未新增读取参考正文的路线，不扩大本次真实调用授权。
