# 知识库准备暂停后的刷新与继续

2026-11-21，BACKLOG351／清单13。DeepSeek发现并实施，Codex正常API独立复现、给范围、全差异审查及验收。

建库成功后暂停，尚未上传的资料没有远程文档ID。旧刷新跳过这些资料，却又把缺少索引状态当成Dify返回未知状态，任务变needs_input，正常页面失去继续按钮。当前把已提交与未提交资料分开：只读取已提交文档的真实状态；仍未提交且没有实际远端错误时，保留/恢复paused，说明尚未提交并保留主动继续入口。刷新不会自动创建、上传或续跑。

已提交资料的真实未知状态、索引错误、暂停或无可用片段继续优先报告needs_input，不能因另有未上传资料而掩盖。所有资料实际完成前不能加入任务。明确继续沿用已有库、Key和已上传资料，不重复操作；旧版本误留needs_input的记录可通过刷新恢复正确状态，不改原回执/任务配置或自动启动。

本轮集成检查同时发现349同源保护与资源目录错误映射的兼容问题：连接在第一次读取后变化，后续请求已被正确阻止，却被目录接口转成502。DeepSeek补三个只读目录的environment_changed→409分支，其余坏地址/凭据/HTTP403诊断保持；旧自然续接测试改为变化时只有一次读取，并显式断言无parameter-rules请求，未弱化同源保护。
