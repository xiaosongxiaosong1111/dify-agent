# 撤销本页流程编辑（0.316）

流程编辑区有未保存修改时，可点“撤销本页流程编辑”，恢复**本页已读取的已保存计划**，清除本页流程dirty标记；不会请求后台、清空已存计划、推进修订、改变确认、成果、运行或费用。空计划回到空编辑器，Workflow、Chatflow和Agent使用同一入口。暂存草稿面板已有“回到正式计划”；新入口可以直接从编辑器操作。

撤销后提供“恢复刚撤销的流程原文”，原文按完整字符串在当前页暂存一次，不解析重写，坏JSON、格式与表情可原样找回。仅同任务、同修订、尚未继续编辑且当前仍是恢复后的基线时可用；有新编辑不覆盖，下一次撤销替换单个恢复槽。离开任务／修订变化或刷新关闭不提供恢复，不写浏览器存储、文件或后台。需要长期保留请另存或使用原暂存草稿功能。

恢复已读计划使用原精确文本路径，原计划含超安全整数时不从舍入对象重建；缺完整来源则保持现有编辑并提示，不强行撤销。这里恢复的是本页快照，后台可能已有新修订，需另行刷新核对。其它需求、配置、样例及对话草稿保持；需求等有未保存内容仍按原规则阻止切换，不将撤销流程当作全部撤销。

0.315保存前变化入口同时补到Agent编辑区，与Workflow／Chatflow共用面板；Agent只显示顶层类别，不伪造节点对比。它和撤销均不自动保存、确认或触发模型/Dify请求。
