# 人工审核草稿（0.120，已部署）

首批适配Workflow根human-input的文字审核、approve／reject两个明确动作，以及__timeout节点超时路径。三路各一条显式出口、独立入口、均能到达终点；审核对象只接全路径上游已声明文字，不能引用兄弟分支、数组／对象／数字或未适配人工节点输出。

完整配置保留form_content、inputs=[]、user_actions、timeout、timeout_unit和delivery_methods。动作含明确id／title／button_style；送达只有一个{id:UUID,type:webapp,enabled:true,config:{}}；小时上限1—72、天上限1—3均要求真正整数。未适配字段、邮件／其它渠道、补充输入／选择／文件、Chatflow／Agent、容器／定时组合明确拒绝，不替换类型或清空后算完成。

原生分支选择使用动作ID；__action_value是动作标题，不是ID。首批没有把人工节点的__action_id／__action_value／输入或渲染结果暴露为可引用输出，避免超时路径缺值；以后加入输出须单独做路径可用性验证。节点超时与平台全局过期不同，全局EXPIRED可能直接停止流程，不保证走__timeout。

前端有人工审核配置卡与三路技术样例，修改仅进入未确认草稿，保留动作／交互UUID、连接和其它节点。审核对象、等待、标题／样式及同结构手改可静态核对；保存不能证明已送达或用户已经提交决定。人工草稿新增human需求专项；核对审核对象／角色／入口／权限／等待和三种结果，草稿不能自证业务决定。

运行边界：通用入口暂不导入或运行含人工审核节点的成果，IR与最终成果都检查。0.122另有纯模板单根审核的[专用资源方案](human-runtime.md)，用户另行批准才可执行；实际平台联调尚未验收。本草稿入口只支持生成、静态检查、同结构手改保留与下载；不会创建表单、发送通知、替用户提交或触发恢复。WebApp送达和访问限制、真实等待／恢复、全局过期、邮件与外部渠道仍待开发／验证。T116尚未整体完成。

验收建议的摘要包含完整审核文字、动作／时间／交互字段和连接，轻量scope16；旧scope15不能自动升级或回退主模型，须明确重新确认范围。不会发送已提交审核内容或通知凭据。
