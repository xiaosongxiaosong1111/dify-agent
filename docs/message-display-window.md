# 长对话的本页显示窗口（0.321）

打开任务时，默认只在页面绘制最近50条对话。上方显示本页真实区间和总数，每条记录保留原来的零基 `message:N` 索引、角色、时间及修订说明；可主动查看更早50条、较新50条或回到最新。最早不足50条时显示实际数量，不补记录或漏掉窗口之间的消息。

翻看旧窗口时，同一修订追加消息会提示新记录数量，当前窗口保持，不强行跳到最新。主动回到最新后显示新增原话。切换任务、离开后返回或业务修订变化，会清除旧窗口和正文展开状态，避免沿用旧来源。

单条正文默认最多4000个UTF-16单位，每次只允许一条扩大到最多16000单位；切窗口或展开另一条会收起之前的预览。边界避开有效代理对中间位置，不拆开emoji。是否未完整显示会明确提示，扩大预览也不把超长记录说成全文已读。后台原话仍保留，已有历史查找/完整核对入口按其自身范围工作；本页不承诺可完整预览任意大小正文。

这里只减少页面DOM中的消息与正文，不删除、压缩或修改后台历史，不改变模型上下文、需求、确认或费用；也没有减少当前Task详情传输或实现数据库分页。最新窗口一般最多绘制约21.2万个正文UTF-16单位，消息原文仍已随Task详情读入，不能把它当作全部长历史内存或网络问题已解决。

旧版123条消息全部生成DOM已复现。新增8项隔离界面检查与历史原话查找/核对/明确引用8项回归及构建通过；覆盖连续窗口、超长emoji正文、单条展开、追加保持、修订/任务切换和零浏览写入。首轮刷新断言未等待异步回执，改为等待新记录提示，原失败日志保留，未改生产刷新逻辑。测试只在临时Store明确追加一条公开消息及改变一次夹具修订，后台原历史/其它业务字段和原16保持，真实模型/Dify新增0。

0.321受管理部署271文件、health及前端200。后台仅版本变更，未重复无关后端或跑全量；非长期记忆、模型省Token、全文语义查找或全应用性能验收。
