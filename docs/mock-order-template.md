0.272只能声明模拟依赖、关联位置与保存接入待办。本版增加一份可审查、可主动采用的订单查询代码模板：用明确给出的合成订单表查询，返回命中、未命中或缺少订单号的固定结果。

## 使用

1. 在配置页明确声明模拟依赖并保存。若已有逐项位置绑定，须与本次选中的代码节点一致，模板不会修改绑定。
2. 流程页须已有通过结构检查的根代码节点。打开“订单查询模拟模板”，明确选择依赖、要替换的节点和文字输入来源。支持Workflow/Chatflow；不新增节点、连接或Agent工具。
3. 填写1—10个合成订单号及固定说明，例如`{"DEMO-001":"合成样例：已发货。"}`。订单号为1—64位字母、数字、横线或下划线；每条说明最多500字。不要填写客户资料或凭据。
4. 明确接受替换选中节点的完整代码、输入绑定和输出声明后，点击“准备订单模拟模板（不保存）”。可查看完整建议，预览不改正式任务、确认、成果或费用条目，也不执行代码。
5. 主动采用才放入未保存编辑器；保存计划、重新确认配置和静态构建后可下载。下游仍引用模板不提供的旧输出时，建议会拒绝，不删业务引用或重连后放行。

模板固定输出`result`和`status`，保留目标节点ID/标题及其它节点、连接和配置。支持开始节点的明确文字字段；Chatflow也可明确选择整条sys.query直接作为订单号，不做自然语言抽取。输入去除两端空白后按大小写精确匹配；None/空白按缺少订单号处理，数字、布尔等不转成文字。入口为必填时，Sierra仍可能在派发前拒绝缺失输入，模板不会改变入口规则。

| 结果 | status | result |
|---|---|---|
| 合成订单命中 | mock_found | “【模拟订单查询，非真实订单】”加提供的固定说明 |
| 未命中 | mock_not_found | 带同样模拟标记，说明合成样例无该订单 |
| 缺少订单号 | mock_missing_order_id | 带同样模拟标记，请提供订单号 |

其它字段、订单真实性、物流状态和鉴权均不推断，没有真实接口请求或退款操作。
