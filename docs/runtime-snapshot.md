# 固定运行快照

0.79.0，解决开发文件变化影响运行中服务的延迟模块／模型契约及旧前端按需加载资源的问题。

启动器先对后端代码、已构建前端和7份运行所需模型契约计算完整文件清单／SHA256，创建 .runtime/snapshots/版本-内容哈希。不复制任务数据、凭据、work、测试或Python环境；快照目录不允许指向其他位置，缺完整入口／契约拒绝启动。已有快照须清单和每个文件哈希一致，否则不覆盖／启动；新代码／契约／前端形成新快照，旧资源保留，不自动删除。

uvicorn从快照backend启动，模型契约及前端也读同一快照。FLOWCRAFT_DATA_DIR明确保留原环境配置；未配置时使用原project/data。启动子进程后还原启动器环境变量；PID／日志保持原项目目录。快照缺显式独立数据目录或数据指向快照内时拒绝初始化，避免生成新任务库或凭据。

启动／停止共同核对准确的app-dir、uvicorn app.main、127.0.0.1及8765；支持原开发目录进程及有完整身份清单的本项目快照进程。其他项目、相似目录名、其他模块或端口不会被当成本服务停止。启动未改变已有进程时不会自动升级版本；更新仍需等待活动任务和待结算调用结束，再停止已核对的本服务并启动。

GET /api/runtime只读当前版本、启动模式、快照ID／内容哈希／文件数量及数据是否在快照内，不返回数据路径、凭据或文件正文。不以损坏清单推断身份。Python依赖环境仍与项目共享，不是完整依赖隔离或容器发布；快照是本机代码／契约／静态资源的固定副本。
