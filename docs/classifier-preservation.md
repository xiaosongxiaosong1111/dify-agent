# 分类节点手改保留与验收语义

0.61.0 将 0.60 的顶层文字分类节点接入实际 DSL 差异／合并／重新确认／构建路径，以及验收建议的最终文件语义摘要。

分类说明、类别顺序和首项、标签、补充指令、问题 selector、完整独立模型／参数和布局按用户当前文件保留，不用旧生成计划覆盖。实际文件重排类别会改变原生首项回退，须结合差异及配置重新确认；虚拟 IR 只用于静态核对原生事实，不会把 unmatched_policy 作为新参数写入用户文件。

支持标准 Chatflow 有界历史结构（对应 1—50 历史轮次）；独立／无界／自定义模板、视觉、动态类别、容器内分类、格式异常或未完整模型参数明确拒绝。未适配内容留在原文件，不能移除或把 False／null 转空后宣称保持。实际图仍检查全部类别出口和文字引用。

验收建议读取当前最终文件的 classes 顺序／ID／说明／标签、instruction、query selector、model、memory、vision，并说明当前首项原生回退事实，不包含原始运行输入／输出。摘要深复制，不回写源图，仍有已有内容／大小／凭据限制。布局等非语义字段按原文件保留，摘要明确省略，不把它们当业务行为。

由于数据范围新增分类业务内容，轻量验收路由 scope_version 升为 6。旧启用范围 5 必须重新阅读完整范围并主动确认；未确认不派发，也不自动退回主模型。关闭路由也需按当前范围请求确认，历史费用不清空。本次开发不代表批准把用户业务信息实际发送给供应商。

11 项新增本机检查，完整修改—读取—合并—确认—构建—最终语义路径以及旧轻量范围5阻止均通过，分类／语义／路由相关51项通过，最新完整后台1606项通过，既有Starlette提示1。模型全部替身，没有实际供应商调用或 Dify 资源写入。分类准确性、真实往返及新环境资源仍待实际业务验证，不能将静态保留当已运行。
