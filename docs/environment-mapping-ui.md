# 原生 Agent 的目标环境映射草稿

0.226，2026-10-19。目标 Dify 1.17.1 / DSL 0.7.0。该界面准备待验证文件，不迁移实际应用。

在构建页上传或读取当前 DSL，分析并处理全部冲突。仅单个受支持的原生 Agent 包通过静态检查后显示“准备跨环境目标草稿”；不将 Workflow 或 Chatflow 转成 Agent。

1. 选择与来源不同的目标环境连接；环境版本是本机声明，未在线核对。
2. 填写完整目标模型 JSON。可先填入来源模板，必须明确核对目标型号、参数、插件与费用。JSON 原文交后台校验，浏览器不解析再重写数值。
3. 对当前全部来源知识库逐一填写目标 UUID；不按名字猜测，不把多个库合为一个。相同 ID 也须明确填写，ID 对应不证明资料范围等价。源库名称和描述不冒充目标标签。
4. 按需填写目标市场插件完整标识。源文件有固定依赖且换插件时必须填写；保留标识不证明目标已安装。
5. 勾选目标资源待验证声明，再预览全部变化和 YAML。可下载文件名带“目标资源待验证”的文件；文件说明也带未验证标记。未执行模型、知识库、HTTP 或 Dify 请求。
6. 主动保存完整预览后，可在重启后恢复。恢复清除旧勾选与结果，必须重新核对并预览；保存不会改变业务任务的环境、配置、产物或确认状态。

未完成输入目前只在本页暂存，刷新可能丢失；后台保存的是已经完整预览的进度。未存输入会阻止任务切换、来源读取、重分析和采用，跨工作台页面仍保留。可明确清除本页输入来解除保护，后台记录及历史保持。

读取最新保存版本不会覆盖本页输入。版本不一致的保存会被服务器拒绝；读取核对后才能决定是否重新保存。历史可按版本号读取；来源、目标上下文变化时旧版本只读。即使服务器可读，记录的来源摘要或冲突选择不同于当前页面，也不会混用恢复。

可选展开“读取目标资源目录”并主动读取。模型返回状态／标识，不自动覆盖完整JSON；知识库可选管理连接或知识库Key，不自动扩大权限，按页主动读取，每页100条。同名库不自动选择，需逐库选择并明确填写；目录展示来源时间及分页范围。目标连接修订变更、坏结构或读取失败会拒绝旧目录，已填写输入保持。目录声明不证明资料内容等价、费用或实际调用成功，未验证标记保持。

完整映射保存后可经明确范围确认创建独立本机目标任务，来源保持，详见[说明](environment-mapping-copy.md)。尚无实际平台迁移验收。复杂检索、自定义工具、文件、Skills、多包等原有缺口不会通过映射被省略。T110 仍为部分实现。

证据：192 项相关后端检查、14 项源资源及 14 项部署资源界面隔离检查、13 项既有模型采用界面回归、TypeScript/build 通过。界面回执使用模拟数据，业务 API 检查使用临时 Store；原 11 任务、加密凭据和密钥保持。最近完整后端回归为 0.217 的 4577 项，不冒称 0.221 完整或真实迁移验收。

0.222追加22源＋22部署静态资源界面隔离检查，覆盖目录手动触发／分页／ID选择／失败与旧身份。后端目录接口未改，仅版本变化，未重复后端回归。没有实际目标目录请求，不能把合成目录回执写成真实平台成功。

0.225 可在目标模型目录下选择型号并主动读参数规则。逐参数填写单个JSON标量（文字需双引号）；必填值不默认补齐，可选值主动纳入。先生成完整候选，再明确确认替换主JSON，不继承旧型号参数。数值原文保持，语法通过不代表精度、范围及供应商规则已全部通过；仍须后台完整映射检查。参数草稿锁住目标及来源，撤销保持主JSON；目标上下文变化时旧草稿只读。目录未声明Temperature/Max tokens或超过32规则时不做部分表单，完整规则仍可查。36源＋36部署静态资源隔离GUI/build通过，无真实目录或模型请求。

0.226完整目标JSON可主动“按目标目录核对完整模型配置”：只读重新取目录及参数规则，显示读取时已知规则一致／不符／不足。不会补默认、改参数、验证模型调用或批准资源，全部映射仍带未验证标记。核对回执绑定连接修订及输入原文摘要，失败撤旧结果。诊断不强制替代待验证DSL准备，也不能作为导入/运行门禁的替代。详见[核对说明](model-configuration-check.md)。
