# 每个 LLM 节点独立选择模型

版本 0.27.0，适用于 Workflow／Chatflow 的文字 LLM 和单层迭代内部 LLM。原生 Agent 继续使用独立 Agent Plan，不套用此规则。

流程页提供逐节点配置来源：继承任务模型或独立选择。独立节点可以读取 Dify 实际模型目录及参数规则，明确采纳后填入本地流程草稿；也可以主动复制任务模型作为独立配置，或在离线条件下手填标识及完整参数。读取、选择和填写都不保存、确认、导入或运行。保存计划后配置确认和旧构建结果失效，按新修订复核后才能继续。

## 严格配置契约

LLM 的 config 可选 model。缺少此字段时继承任务的供应商、型号及完整模型参数。存在时必须完整填写以下对象，不接受 null、空对象、局部字段或未知字段：

```json
{"provider":"实际供应商标识","name":"实际型号标识","mode":"chat","completion_params":{"temperature":0.2,"max_tokens":2048,"thinking":false}}
```

temperature 为有限 0—2 数值，max_tokens 为 1—1000000 整数，实际模型规则仍需核对。其他参数采用已有平铺标量规则，不能包含连接地址、密钥／令牌、密码或嵌套配置。示例标识只说明结构，不能作为真实可用资源使用。

独立模型完全替换本节点的模型对象，不从任务模型或其他旧型号隐藏继承额外参数。界面手动更换供应商会清空旧型号和全部参数；更换型号清空全部参数，需明确重新填写或采纳。参数 JSON 无效时原文字进入未保存草稿，后台拒绝保存，不沿用旧值冒充修改成功。

全部 LLM 已独立选择模型的流程不强制填写无用的任务默认模型；只要有节点继承，任务模型仍是确认／构建的必要条件。任务中的 Sierra 助手供应商不因此改变。Chatflow 记忆政策仍来自任务配置，迭代内部依旧不读取会话历史。

## 资源与费用边界

目录与参数规则是当前 Dify 声明，不证明真实执行或所有业务质量已验收。手填、复制任务模型及静态校验也不能证明插件、模型或参数已可用。不同节点、并发／迭代项和历史输入可能增加调用量、限流与实际费用；Dify 执行费用仍不受助手预算硬限制。

本版支持文字 chat 模型与平铺参数；completion 模式、视觉、嵌套模型参数、结构化输出专门配置和运行时自动切换不在本批支持范围。不会因为缺少模型就偷偷换供应商或删除节点。

backend/tests/test_node_models.py 验证完整替换／继承、独立多模型、内部节点、参数和秘密字段拒绝、Chatflow 记忆，以及隔离确认／构建／修订失效。页面和全量结果以 development-status.md 实际记录为准。
