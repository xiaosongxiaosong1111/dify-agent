# 管理连接与可选加密登录（0.245.0）

Sierra管理会话独立于Dify浏览器会话。连接表单默认不保存密码；用户明确勾选“在本机加密保存登录资料”后，邮箱和密码通过现有本机Fernet存储加密，仅绑定该环境的原Base URL和Dify1.17.1。公网响应、任务/版本、交接、Git及浏览器存储不含这些凭据。环境列表可“忘记登录资料”，删除加密邮箱密码，当前令牌及独立App/知识库Key保持；更改地址或版本会清除已存登录资料，不能发送给新地址。

`POST /api/environments/{id}/login`仍接受email/password，新增严格布尔remember_login，默认false；成功前不替换现有凭据。选择false的成功连接清除先前记住的数据。`DELETE /api/environments/{id}/saved-login`忘记已存资料，不请求Dify。环境公开字段has_saved_login和automatic_login_enabled仅表示本机状态，不代表当前服务器权限。

明确过期或缺失令牌时，在原请求派发前仅自动登录一次并验证应用列表，再继续原请求；同时到达的请求在同一进程内共用一次续期。未过期却返回401时，可自动登录一次，GET最多重读一次，写入不自动重放，须核对原操作。登录失败或新令牌仍401会暂停该环境的后续自动登录，不循环登录/换账号。独立Service/Dataset Key不触发管理登录。登录期间环境/授权/密码变化拒绝写回。认证显示/时间更新不使同一连接的资源提案无故过期。

到期提示仍仅解码有限exp，未验证签名，opaque令牌为未知；页面倒计时本身不发自动登录请求。只有明确管理请求会触发续期。失败需要修正实际凭据/权限，不能承诺任何情况下都免登录。

# 管理连接到期提示（0.40.0）

Sierra 保存的管理连接与用户在 Dify 浏览器中登录是独立会话。管理登录过期后，必须在 Sierra 的 Dify 环境列表点击该连接的“邮箱密码连接”；Dify 8080 页面登录不会替换 Sierra 的本地加密管理凭据。密码不保存，不自动登录、刷新令牌或重发操作。

环境 API 新增 `console_connection`，只返回 state、到期时间、剩余秒数、中文提示和 `local_expiry_hint_not_authentication`。状态分别为 missing / expired / incomplete / unknown / expiring / present。尚未到期也不宣称认证或权限可用；时间信息来自本机解码 exp，没有验证 JWT 签名。历史 capabilities.console=verified 仍是历史记录，不能替代当前时间提示或真实测试。

只读取本机加密 console_token 的有限 exp 整数，不返回 token、邮件、角色、其他 JWT claims 或 CSRF 值；结构／字符／长度／重复字段／递归异常严格处理，无法判断的 opaque Token 显示未知，不能误判为过期。到期不足 5 分钟提示先重连，前端在页面停留期间按单调时钟递减缓存剩余时长，不自动发认证请求。

请求层发现明确已到期管理令牌时，在发送请求前报“未发送本次请求”。未知格式仍由目标 Dify 判断；实际 Console HTTP401 提示在 Sierra 重连，不输出响应正文、不重试、不改变原凭据。独立 Service / Dataset Key 请求不受管理令牌到期阻挡。此提示不是自动刷新机制，也不保证网络／登录配置／工作空间权限正确。

本次真实六场景执行器在用户反馈重新连接后进行一次管理预检，仍返回401；`loop-runtime-live-result.json` 的 cases为空、pending=null，尚未创建／发布／运行技术应用。只读核对目标环境已保存管理令牌确已到期，未泄露或更换凭据。已再次说明正确连接入口，等待用户回复“已看到连接成功”。原六场景资源授权仍有效，无需再次确认，但不重复派发或自行重新登录。
