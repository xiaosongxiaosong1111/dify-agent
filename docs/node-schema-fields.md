# 节点输出字段配置

0.176实现；实际部署和完整验证状态以development-status.md为准。

在流程页的大模型提示词卡中，明确开启结构化输出后，可以展开字段表。每个字段须明确填写名称、类型、必填规则；支持文字、数字、整数和布尔，最多50项。预览后由用户主动采用，只填空白structured_output，不修改模型、提示词、连线、终点或已有校验代码。支持根模型和单层迭代／循环内模型；表单按任务、修订及节点位置隔离。

已有Schema不能被字段表覆盖。嵌套、数组、枚举和范围等规则仍须在完整JSON中填写。手写JSON先保持完整字符串原文，在手动保存计划时由后台无损解析；128000字节内对象，无重复键、非有限数或坏编码，解析后仍须通过原Schema规则（Schema自身最多64000字节）与完整流程检查。非法输入阻止保存，不写部分计划、不解除原确认。关闭结构化输出不会删除原Schema。

后台会完整保留JSON整数。若保存后计划含浏览器无法无损编辑的整数，节点表单禁用并保留完整计划原文编辑入口，不返回舍入结果。手写原文在保存核对前不提供结构化对象候选；保存后应复核原对象引用及生成Schema检查是否仍与新规则一致。

字段表和本机保存不调用模型、Dify、沙箱或新增资源。声明Schema不证明供应商严格遵守，更不证明业务字段真实；仍须明确失败行为、确认配置并实际试跑。
