# 模型工具请求探测

打开“设置 → 模型接入”，在模型卡片点击“准备工具请求测试（仅本机）”。准备页显示当前配置对应的预留估算、256输出tokens和30秒上限；勾选本次费用同意后，点击“发送一次工具请求测试”才发出请求。准备、查询回执及重新打开窗口不会自动调用模型。

首批仅OpenAI兼容Chat Completions协议。固定公开样例请求sierra_probe_echo，参数text为sierra-probe，不发送任务内容。请求使用tools/tool_choice及禁止并行字段；响应必须是唯一assistant函数请求、指定名称和严格JSON参数，文本口述“已调用”、重复参数、额外参数、多个请求及截断均不算通过。字段按[官方OpenAI Chat Completions文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)核对，兼容服务是否实际遵守仍要单独测试。

这里只检查**工具请求结构**，没有执行器，不执行工具、不回注结果、不继续Agent循环，也不自动启用搭建助手的工具调用。工具执行、Agent业务和其他协议不能据此记为已支持。普通文字/JSON/流式调用路径保持，当前原生Agent自定义工具限制不变。

每次请求有独立UUID本机回执。同一UUID重复提交只返回原回执，不再次派发；同一模型同时只执行一个测试。测试结果绑定服务配置及单价摘要，配置变化的旧结果不更新当前能力。回执与通过标记原子保存；后台重启后遗留进行中回执显示终态未知，不自动发送。新的一次测试需要重新准备和明确同意费用。

实际用量只取返回字段；缺失或网络中断保留未知用量和原预留，0不证明免费。HTTP拒绝、重定向、协议或形状错误不回显服务正文、参数或凭据，不自动重试。请求不跟随重定向，最多接收128KiB解码正文；无工具执行、第二模型调用或自动格式修复。探测单独计费并保留回执，尚未计入某个任务的规划预算；预留估算不是供应商账单硬封顶。

本机接口：GET /api/providers/{id}/tool-probe-plan只读准备；POST /api/providers/{id}/tool-probe接收request_id/source_token/acknowledge_cost；GET /api/providers/{id}/tool-probes/{request_id}只读回执。响应禁止缓存，非法/歧义请求不回显输入。旧回执保留原来源，当前通过状态不会沿用到配置变更后。
