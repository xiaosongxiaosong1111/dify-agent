# 助手费用的精确显示

0.180前端修复，实际部署与证据以development-status.md为准。原预算／规划／模型修复预览使用toFixed(6)，可能把非零小额显示为$0.000000。现在统一以十进制文字完整显示；科学计数由数字位移展开，金额本身不转二进制浮点进行格式化。已有数值快照按其可用十进制表示显示，不宣称恢复上游已经丢失的精度。

未知金额显示“未知”；格式、负值或超出安全展开范围时显示“金额格式待核对”，不回显异常原值或当作0。真正的0仍显示$0。规划逐次记录未给估算或预留时不再默认0；预留仍保留预留标签，不当作实际费用。

仅修正显示，不改变预算、预留、计费、账单登记、模型路由、用户确认或派发行为。估算仍不是供应商账单，手工账单仍须原独立确认，费用未知不能当作免费。
