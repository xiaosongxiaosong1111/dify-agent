# Workflow 数字与选项输入

0.73.0，适配 Dify 1.17.1／DSL 0.7.0。用于金额、数量、业务类别等入口；Chatflow／Agent 的应用变量和文件输入仍未适配。

- start.variables 支持 text-input、paragraph、number、select。number 为有限 JSON 数字，布尔值、数字文本和空串不转换为数字。
- select 有 1—100 项非空唯一文本选项，每项最多 1000 字，保留原文及顺序。默认值必须属于选项，不默选首项。
- required 为布尔值；必填省略或 null 拒绝，即使有 default。可选 number／select 必须明确有效 default，省略或 null 交由原生使用默认；首批不支持下游空值类型。数字默认值 0 保留。
- min/max、整数或金额业务约束不伪造为原生字段，应通过条件／代码及业务验收另行明确。数字／选项未知配置拒绝；原生 description／hide 保留。
- 类型声明用于条件、聚合、循环／迭代外部引用。数字不会误识别为字符串；select 可作文字来源。
- 实际 DSL 手改变量、选项、默认及布局保留，验收摘要使用实际 variables。运行关口从当前成果读取，在新 pending、次数累计、重复失败一次许可消费及外部请求前校验，错误不会启动试跑。原始输入不转换，遗漏可选值不会填进历史记录；输入身份和样例比对保持。
- 输入卡只写未确认草稿，切换类型不删旧选项或转换默认，未完成数字空串／JSON 原文保留，错误须后台修正。改名或移除输入不改引用；完整入口 JSON 仍可编辑。
- 样例建议契约包含实际类型、options／default／max_length，拒绝数字文本／布尔值及非法选项。轻量既有输入声明／计划／最终语义发送范围没有新增类别，scope9 不变。

## 0.209：原文与任务隔离

自由试跑完整JSON按任务在本页分别暂存，切换固定样例只读展示原样例、返回自由输入恢复原稿；不会存浏览器或后台、自动发送或沿用验证。刷新／关闭前请另存。旧输入不保证适合新的成果／修订，须重新检查。浏览器不能安全传递的非有限数、超安全范围整数或超过检查规模时，字段表和对象化检查暂停、运行提交被拒绝，完整JSON文字保持。请明确修正表示，助手不代你把业务数字改成字符串、舍入或null。普通JSON小数仍遵循浏览器数值表示，并非任意数值词法逐字精度保证。


## 0.210：重复字段与数字意义核对

完整自由JSON重复字段（包括Unicode／转义后相同字段和嵌套对象）不能由浏览器选择末值后派发。数字原词法与浏览器序列化的十进制意义若改变，例如1.0000000000000001被舍成1、1e-999变0，会在填写／检查及运行提交前拒绝，不改成字符串或自动选择值。普通0.1、1.5与1.5000等同义写法可用；这不是IEEE754二进制任意精度或目标平台数值保证。完整JSON只检查200万字符、100层嵌套和有界键／值规模，超过明确暂停，不截断。用户须在原文明确修正；原完整草稿保留，任何后台规则及真实派发确认仍独立。


后端三个试跑相关POST也独立核对线格式：重复JSON键、非法UTF8／对象根、非有限与浮点解析改变数值拒绝，错误不回显输入。8MB请求线格式／10万值是额外有界检查，不替代本机检查2MB等更小输入限制；不会放宽Schema或运行许可。后端整数字面量可原样解析，浏览器可编辑／派发能力仍受安全范围限制。
