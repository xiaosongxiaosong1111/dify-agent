# 固定文件验收样例

适配目标：Dify 1.17.1 / DSL 0.7.0。适用范围与文件试跑相同：根 Workflow 的三节点原生提取、四节点单文件模型处理、五节点规范列表拼接后模型处理；TXT、MD、CSV、JSON、YAML、YML。

## 使用

1. 在运行页明确暂存、批准上传文件，填好“本次完整输入JSON”。此处只接受当前任务的可信 Sierra 上传引用。
2. 展开“固定文件验收样例”，点击“读取固定文件样例”。填写样例名称、是否必选和预期规则，点击“将当前输入保存为固定样例”。
3. 样例将文件引用转换为 `sierra_file_fixture`，只包含原始字节 SHA256、大小及后缀；普通参数原样保存。列表保留顺序、重复项及空数组。文件名不是匹配依据，同后缀重命名且字节相同可匹配；改名为其他后缀不能匹配。
4. 后续使用当前修订、成果和目标连接下重新上传的同一文件，点击“选用样例”，填入当前可信引用及原普通参数，再准备单次文件试跑方案。指纹不符、顺序／数量不同或参数变化会阻止准备，不会降级为自由运行。
5. 方案列出固定样例、预期规则和样例集版本。核对文件解析、数据流及目标后，明确批准这一次运行；模型出站、费用未知及列表拼接仍各自确认。
6. 运行后点击“读取固定文件样例”查看判定；需求页样例汇总及交付报告同步汇总固定文件样例。自由文件试跑不会被计为固定样例通过。

## 预期规则

复用普通验收的 `contains`、`equals`、`json_keys`、`json_schema`、`manual`。例如：

```json
{"mode":"contains","target":"result","expected":["合同","日期"]}
```

`target` 指向结束节点输出的点分路径。模型 JSON 仍是文字时，JSON 规则沿用严格完整文字解析，不自动去包装或修复。

人工规则例：

```json
{"mode":"manual","description":"对照原文核对关键条款是否完整，不能只看关键词"}
```

此规则成功返回后仍“待核对”。在文件样例卡填写理由，明确选择通过或未通过，保存人工来源与历史。人工意见不能覆盖自动规则失败。

样例输入、预期及运行方案提供后台完整 JSON 原文用于展示和编辑；超出 JavaScript 安全整数范围的值不会先在浏览器中重序列化再保存。后台仍按严格 JSON 类型和数值匹配，不把相近大整数视为相等。

## 生命周期

- 文件样例集是独立的本机记录，每个成果最多20项。保存不修改任务修订、原任务样例、成果或已上传记录，也不触发上传、发布、运行、模型或其他外部请求。
- 保存、编辑和移除增加样例集版本；全部旧固定样例试跑方案与旧通过结论不再计入当前集。界面读取使用乐观版本检查，避免覆盖其他修改。
- 当前修订、成果字节、目标、相关连接或执行策略变化会使样例集过期。旧集可查看，不能直接复用；明确勾选归档旧集后，才从当前可信输入建立新集。不会把旧文件 ID 自动改绑。
- 最近20份旧集快照保留在本机数据库；点击“查看文件样例历史”可读取最近保留旧集的索引及逐项变更，再主动查看某份完整定义；界面没有恢复入口，不会把旧定义改绑到当前成果。达到20份保留上限时会提示更早历史可能缺失。移除样例不删除上传文件或 Dify 资源。
- 正在核对／运行文件方案期间不能修改样例集。派发前还会重新核对当前集、文件证明及上下文；变更则停止。运行中断／失败不自动重试。

文件指纹相同只证明原始字节匹配，不证明 Dify 实际解析、文字完整性、模型质量或客户业务已验收。规则通过只证明已声明的对应条件。真实平台文件验收仍须按具体资源方案单独批准；本次开发验证使用隔离数据库和模拟平台。

## 本机匹配已上传文件（0.159）

在固定样例卡点击“匹配已上传文件”。系统只查询当前任务、修订、成果、变量、目标及凭据下的可信上传记录，不联网读取正文或核对远端寿命。唯一记录先形成预览；同指纹有多条记录时，明确选择各位置后再次匹配；缺文件会列出缺口，不自动上传或跳过。

核对将替换的原输入及匹配后的完整输入原文，主动点击“用此预览替换本次完整输入”。普通参数来自固定样例；采纳会清除旧试跑方案和确认，随后仍须准备、批准单次运行。不会因匹配就派发运行。

## 历史核对（0.160）

历史页只展示保留定义及到下一份样例集的新增／移除／修改字段，不重新计算或继承历史通过。原目标未记录的早期快照显示未知，不能借当前连接补猜。当前取样会保存公开目标元数据，供后续历史查看。完整定义按指定版本读取；历史不存在或已超出保留范围时明确报错，不返回其他版本代替。

## 对照原运行输出（0.161）

样例有原运行记录时，点击“查看此样例原运行输出”，直接读取本机已保存的该次回执及当时固定输入／预期。不会重新请求Dify或模型。原修订／样例集版本明确显示；是否计入当前验收仍看当前样例汇总，查看历史不会恢复通过。

输出预览最多64000个UTF-8字节，截断会明确提示，片段可能不是完整JSON。可主动下载完整已存输出JSON，下载必须匹配预览所列SHA256；结果变化则拒绝替换下载。只有明确成功的已存文字／文字列表输出可下载，失败或未知不会伪造成功结果，也不自动重跑。人工复核依然需要当前样例及明确理由，查看输出本身不提交判断。
