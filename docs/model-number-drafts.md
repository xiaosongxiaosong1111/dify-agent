# 两个模型数字文字的独立本机草稿

0.230，2026-10-19。只保存 Temperature / Max tokens 的文字进度，不保存整张配置表，不自动应用或确认参数。

配置页展开“保存和恢复数字文字草稿”，可主动保存包括 `1e`、空值、超精度小数在内的原文字。仅限每项 2048 字以内的 ASCII 数字、e/E、正负号、小数点及空格；其他文字、多行、超长或疑似凭据内容不会截断保存。两个文字与本机任务修订及**后台已存**模型、环境、扩展参数绑定。

模型或环境相关配置尚未保存时，数字进度不会被绑定到另一型号；会说明原因并保留本页输入。其它未存配置也不会因数字草稿按钮而保存，刷新前仍需单独留存。

读取最新进度不会覆盖本页。恢复必须先勾选明确覆盖确认，服务器再核对修订、上下文、草稿版本和摘要；仅将文字放回本页，不修改 Task 配置。修正后若文字与有效配置不同，须明确采用，再保存配置。旧勾选、配置确认与运行证据不沿用。

保存过进度后，可明确“暂时退出本页数字编辑”：只退回后台已保存的两个数值，其他配置草稿及后台数字进度保持。若没有其它未存修改，此后可切换任务。回来或刷新后，再明确恢复原数字文字继续工作。

并发更新不自动覆盖；相同内容保存幂等。新进度将旧记录准确归档，可按版本读取历史；历史读取也不覆盖输入。任务修订或模型／环境上下文变化后旧文字只读，不跨型号直接恢复。可参考原文重新填写，但不能把旧参数当作新型号已经核对。未知归属、损坏计数／时间／字段或孤立历史不会被当作零版本覆盖。

实现只在独立本机表中保存数字文字及元数据；模型上下文正文、凭据不写入草稿，操作不解密凭据、不请求 Dify 或模型、不改业务任务、产物、审批或预算。读／恢复仅为本机未确认进度，不是参数、资源或业务已验证。

API：`GET/PUT /api/tasks/{id}/model-number-draft`，`GET .../history/{draft_revision}`，`POST .../restore-preview`。写入／恢复绑定 `revision`、`model_context_json`；保存有 `draft_revision`，恢复有 `source_draft_revision` / `record_token`。原文字用字符串传递，禁止先解析重写数值。
