# 运行诊断的节点耗时与用量

0.36.0，2026-10-12。只扩展已授权只读诊断的字段展示，不派发模型、修复、重跑或改变验收。

本机 Dify 1.17.1 原生 `WorkflowRunNodeExecutionResponse` 已核对 `elapsed_time`、`execution_metadata`、`retry_index`；容器实际 `WorkflowNodeExecutionMetadataKey` 枚举确认 `total_tokens`、`total_price`、`currency`、`iteration_id/index`、`loop_id/index`。只提取这些字段，不复制 inputs／outputs／process_data、工具参数、循环状态、客户原文或任意 metadata。容器标识脱敏，索引按平台原值展示，不猜测从0／1开始的业务轮数或实际完成次数。

每个执行记录独立展示耗时秒、tokens、报价及币种。已知0保留，但不证明免费；缺失、非有限／负数、布尔代替数字、过大或格式不兼容显示未知并列原因，不转换成0。价格与币种同时有效才标已知，币种需三位大写字母；不汇率换算。沿用已保存费用字段的有限非负十进制约束，非供应商账单或费用硬上限。

父容器可能已含内部节点用量，子节点再相加会重复；并行的节点耗时可能重叠。因此不将逐节点价格／token／时间相加为应用总费用、运行时间或累计预算，也不写入原试跑的费用返回。独立费用报告继续只用原已保存的应用执行字段。旧诊断无指标时显示未知，已有证据及验收不变。

诊断仍绑定原任务／修订／环境／应用／workflow_run_id；缺可信来源时只分析本地，读取失败保留本地证据。Agent完整节点轨迹及运行自动修复仍未适配。本轮只使用隔离受控远端响应及字段枚举读取，无真实业务轨迹请求或新付费模型调用。验证记录见 development-status.md。
