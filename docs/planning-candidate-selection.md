# 按字段选择保留候选（0.254）

在“读取保留流程候选原文”之后，可读取当前已存方案与该候选的字段差异。默认全部不选，逐项查看前后预览，再勾选所需变化、合成原文并明确载入未保存流程草稿。完整候选入口保持。适配Workflow、Chatflow及Agent的本机计划对象，应用类型保持。

没有自动判断“业务目标变化”。未选部分逐值沿用当前已存方案；用户仍须校验并明确保存，保存继续走原修订失效/确认规则。比较/合成本身不写数据库、不改正式方案、修订、审批、成果或App，不发模型/Dify，不冒充静态、平台或业务通过。

差异读取及合成绑定任务、当前修订、类型、规划记录、完整候选/基线原文摘要、当前需求/配置及暂停代数。仅同修订暂停/中断且有完整候选与已存基线时可合成。来源改变/重复或未知选择项拒绝；历史修订仍只读，不映射到当前任务。完整候选中疑似明文凭据、超深结构/过大/超过400项变化均整次拒绝，不返回局部可误解的差异。

字典按字段比较。只有节点ID和顺序完全相同的nodes列表可继续到节点内字段；其他列表、节点增删/重命名/重排按整组显示，明确选择会包含组内所有变化，不按位置猜配对。普通输入/输出列表也是整组。预览最多1200字符并标截断，合成使用服务器完整值，不从预览补齐。整数/布尔/浮点严格区分，精确大整数仅通过JSON原文传输，浏览器核对字节及SHA256后直接载入文字。
