# 已有订单模拟表的继续编辑（0.280）

订单表原先只进入生成代码，刷新后表单为空，继续修改需要手工从代码中找出数据。现在流程页“订单查询模拟模板”支持明确选择依赖和代码节点，再点击“载入选中模板的合成表（替换本表单）”。

载入会替换本页合成订单表和订单号来源，清除旧替换确认与建议；它不修改计划、配置、任务或预算，不执行代码。可以编辑数据，再按原流程明确接受替换范围、准备单节点建议、主动采用到未保存草稿、校验保存、重新确认配置并构建。已有其它分支、节点和连接保持，旧修订成果与历史保留。

后台只识别当前代码及输入/输出声明完全匹配Sierra v1订单模板的内容。以最多64KB/2000 AST节点的只读语法树提取唯一orders字典，键和值必须为文字常量，不使用eval、literal_eval或exec；重复键、表达式、解包及其它类型拒绝。重新生成模板后与当前代码严格比较，仅允许代码换行CRLF/LF差异；手改逻辑、注释或声明不匹配时保留原稿，不猜测还原。数据字面量仍可载入，只要当前完整代码与这些数据构成的模板一致；内容匹配不是历史来源或运行通过证明。

复用原单节点模板的完整流程校验、已声明模拟依赖、位置绑定、输入来源、提取成功保护和1—10条合成表限制。仅根代码节点；支持Workflow/Chatflow开始文字字段、Chatflow整条query和受成功保护的提取string，不扩展Agent或容器内代码。

接口绑定请求修订、nonce、节点、依赖、原稿摘要和返回表摘要，后台解析后再检查修订；页面原稿或作用域变化取消迟到载入，错误归属响应不替换本地字段。错误不回显原文，已识别凭据模式拒绝，不解密密钥或请求模型/Dify。仅填写合成资料，不把数据读取当真实订单接入。
