# 未确认材料文字草稿（0.92）

材料卡可主动保存尚未写完的文字和覆盖范围，保存在独立本机Store集合，绑定任务／材料及登记SHA。草稿不改变Task修订、确认、材料status／正文、成果或模型上下文，不读原文件，不执行OCR／模型／Dify。空内容也可保存，超过100000字／2000字拒绝，不截断。

GET只读；PUT／DELETE按当前Task修订和单调draft_revision检查，材料必须属于当前任务、保存时须needs_input及同一登记摘要。相同请求幂等；删除保留递增版本墓碑，防旧客户端在删除重建后碰巧复用数字覆盖新副本。移除保存副本不删除原文件或当前页面输入。

任务修订变化时，登记原材料未换且仍needs_input的文字可以主动恢复，来源确认必须重新选择；已采用正文或材料摘要变化，保存副本保留可读但不能恢复／覆盖。草稿只绑定登记摘要，不声称原文件已核对，正式采用仍走0.91实际文件SHA及人工确认。

读取不会自动填入。替换页面未保存内容须明确接受，恢复清人工来源确认；409／错误／错任务响应保留当前编辑，阻止继续用旧版本写入，先只读刷新。草稿内容不存浏览器存储。补开发源5173的PUT预检支持，未扩大允许Origin。
