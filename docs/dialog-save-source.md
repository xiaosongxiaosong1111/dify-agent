模型/环境保存、新建任务与改名的返回结果绑定发起弹窗会话和输入来源。关闭或输入变化后，晚到成功只合并对应保存列表，不关闭/清空后续窗口或自动打开旧创建任务；晚到失败不污染新表单错误，原窗口未变仍正常采用。
