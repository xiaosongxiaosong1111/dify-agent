# 知识库索引的有限平台跟踪（0.326）

打开知识库准备记录时不再默认查询Dify索引。执行中或暂停后仍有在途步骤时，继续只读跟踪本机回执；这不派发新的资源步骤。已有“读取实际索引状态”仍是明确的单次平台读取。

索引中且方案仍属当前Task修订/环境时，可明确选择“开始有限平台索引跟踪”。每轮先核对本机权威记录，再读取平台索引；同一轮不并发。最多20轮或2分钟，边界停止后续派发。当前页可明确停止，错误、状态暂停/终态、任务/修订/环境/作业切换或离开配置页都会停止。切换后本机GET晚到不再续发平台POST；重开页面保持关闭，不恢复旧自动跟踪。

一轮可能包含工作空间身份、多个文档状态和认证续接，不等于一次HTTP；20轮/2分钟不是管理请求数量、费用或供应商账单硬限。原真实批请求/费用边界继续适用，不自动扩大。停止/取消浏览器请求不能取消服务端或Dify已经收到的查询/索引/写入，不删除资源。明确启动资源准备后的后台原有首次状态查询保持；此功能只改变界面后续跟踪。

本机或平台读取失败停止自动跟踪并保留原回执，不自动重试；仍有在途步骤时提供明确的“重新跟踪本机在途回执”，只读本机。停止后可按具体授权再次明确开始或单次读取，不自动续接。未知写入仍须核对，索引就绪不等于检索质量或业务验收。

先复现旧界面180ms加速计时即8次默认平台POST。修正后新UI10/原暂停恢复UI5、51项相关后端及构建通过，未全量。覆盖20轮边界、读取跨2分钟、错误无重试、停止/切页期间晚到、错任务回执拒绝、单次入口和本机暂停不续发。隔离计时仅加快2秒轮询，时间边界另以受控时钟验证；真实模型/Dify0，原16/账本密文主Key/消费124保持。不代表真实平台自然索引恢复或全部事件服务验收。
