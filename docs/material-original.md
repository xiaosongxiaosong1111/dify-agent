# 材料原文件核对与下载

0.300在每张参考材料卡增加“核对或下载本机原文件”。展开不读取文件，主动核对才按当前任务、修订和材料ID读取本机原字节，比对保存SHA256和已知大小，显示核对时点、观察值与未知项。同名文件分别使用各自ID，不按名称取第一份。保存摘要本身不再被误当成磁盘当前状态证明。

核对成功后可“重新核对并下载原文件”。下载时再次验证当前任务修订、材料归属、原路径和摘要，直接返回本次已校验的字节，不在响应阶段重新打开文件。浏览器也对收到的字节计算SHA256，通过才交给浏览器保存；页面仅说明已发起下载，不假称文件一定保存成功。原始CRLF、BOM、二进制及无法解析的文件保持；不把提取文字、人工文字或图像候选重建为原件。

API为只读`GET /api/tasks/{task_id}/materials/{material_id}/original?revision=N`及其`/original/download?revision=N`。原件缺失/不可读取/路径无法核对、摘要未记录、字节或记录大小变化、超过20MB上限分别说明；非可验证来源不提供下载。旧记录缺摘要不会猜测或读取原字节，缺大小但摘要可核时明确大小未记录。当前材料已移除，即使审计文件仍保留，也不能用此入口读取；不会修改历史、确认或材料正文。

读取严格绑定UUID任务/材料、原后缀和任务目录，拒绝重定向目录、文件符号链接、非法后缀及非普通文件；读取有20MB上限。读取后再次核对修订与材料记录，避免并发变化后仍返回旧来源。附件使用通用二进制类型、nosniff、CSP sandbox及禁止缓存，不以内联HTML/图片/PDF执行原内容，下载名作路径/控制符清理和UTF-8编码。这里是本次字节核对，不是内容正确、完整解析/OCR、模型实际阅读或业务验收证明。

新22项与相关129项针对性检查通过，覆盖同名/跨任务、原字节、旧记录、缺失/变更/大小、权限异常、路径/链接保护、读取期间改修订及参考DSL的原YML/CRLF；图像与人工文字既有路线保持。8项实际界面及浏览器下载检查/构建截图通过，未全量。首轮界面检查在切换任务后立即数旧DOM，已改为等待实际任务渲染完成；未改产品判断来适配测试。
