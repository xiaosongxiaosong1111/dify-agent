# 项目验收映射核对

`docs/acceptance-mapping.json`绑定需求原文SHA256，完整列出AT-01—AT-25的实现入口、相关检查文件和具体剩余条件。存在实现、引用存在、隔离检查通过、真实平台技术验证与最终客户验收是不同结论，不得互相替代。

在项目根目录运行 `.venv\Scripts\python.exe tools/acceptance_audit.py --runtime`。工具只读需求／清单／代码版本和可选的本机8765版本元信息，不导入应用、不执行测试或读取凭据。输出唯一名称的MD到work目录，不覆盖上次报告或用户手改。基线变更、条目重复／缺失、原验收文字不匹配或引用越出项目／缺失时拒绝生成结论。

目前25项已建立实现与检查入口映射，最终结论记录尚未登记。记录数量不是功能实现数量，也不是项目完成百分比。各专项最新运行证据见development-status.md，136任务原计划不会因本工具生成报告而被整体标完成。

主要待办仍包括真实复杂需求质量、批量失败继续与嵌套、通用手改往返、复杂触发与人审环境、跨客户目标复现、同案例多模型受控质量／成本比较和新电脑最终交付。基线或范围改变需先更新需求并人工复核映射；不能通过删掉验收项使报告变“完成”。
