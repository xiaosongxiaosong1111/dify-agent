# Sierra 参考 DSL 整理

0.20.0，2026-10-11。实现 T050 中参考 DSL 的首批结构整理，不包含图片流程图／OCR 或完整业务语义理解。

## 使用流程

在需求页的“整理参考 DSL”专用入口上传 YAML／JSON 文件。先在本机读取和展示应用类型、名称、版本、文件校验值、节点／连接、入口／输出、资源引用及原文摘录，不改任务修订、需求、计划、应用类型或确认状态，也不调用模型。

复核摘要后主动选择借鉴、保留指定部分或严格复现；保留方式须填写具体节点／规则／内容，并明确核对类型差异、未知节点和摘录限制。加入后生成一份已解析的参考材料，保留安全校验通过的原文文件及完整结构摘要。任务推进修订、确认失效、已有计划保留但标为需复核。材料区可再次展开摘要、调整参考方式或移除引用；任务历史保留旧材料。

采用借鉴方式时，已有访谈、需求来源／冲突检查和自动规划将通过材料文本读取摘要；模型片段上限和截断提示沿用既有机制。讨论按钮只填写聊天问题，不自动发送。保留／复现方式仍阻止自动规划／构建，不能把保存材料当作已经复现。与构建页的“保留 Dify 手动修改”用途和记录不同，两者不会相互替代。

通用“上传材料”入口仍仅提取普通 YAML／JSON 文本；需要结构摘要时使用上述专用入口，已有普通材料不会被自动迁移。

## 解析与限制

- 适配基线为 DSL 0.7.0。允许参考的 Workflow、Chatflow 或原生 Agent 类型与当前任务不同，但明确提示差异，不自动换应用类型或绑定同名资源。其他版本／类型须重新导出或提供文字说明。
- 最多 2 MB、250 个图节点和 500 条连接。安全 YAML 解析拒绝重复键、循环／共享锚点、非 JSON 值、过深／过大结构及已知明文密钥模式／字段、带值秘密环境变量。拒绝时不存预览或原文。此检测不能保证识别所有自由文本中的敏感信息，用户应先无密钥导出。
- 校验唯一节点 ID、节点类型／标题、入口输出结构及边引用；保留所有接受的节点和连接。未知节点保留 ID／类型／标题并明确限制，不静默删掉。没有证明图可运行、条件语义正确、代码安全或业务覆盖完整。
- 节点详情摘录已识别字段：开始变量、LLM 文字模板／记忆／上下文／视觉、检索策略、条件 cases、代码与变量、模板、HTTP 请求、迭代、输出或回答。每个字段最多摘录 1600 字，并显示截断；原文保留，不等于完整配置反解或可再生成。
- 模型、知识库和接口标识只来自源文件，没有访问外部资源。HTTP 副作用、视觉／文件输入、迭代子集和未知能力均提示待确认；节点类型可识别不代表全部参数受支持。
- 原生 Agent 识别被引用包的指令、模型、知识集和工具摘录；包继承、Skills、内建权限、完整工具语义和未引用包未展开。当前 query／answer 为 Sierra 文本入口参考，不宣称源包所有输入能力已验证。
- 摘要并未把任意代码转成可信业务解释。业务含义、不确定事实和迁移方案需要后续访谈及用户裁定；本轮没有实际调用模型验证该讨论质量。

## 持久化与接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/tasks/{id}/reference-dsl` | 最新摘要、源修订、采用状态及过期状态，不返回完整原文 |
| POST | `/api/tasks/{id}/reference-dsl/preview` | revision、content、filename，先安全解析再保存独立预览 |
| POST | `/api/tasks/{id}/reference-dsl/adopt` | revision、preview_id／token、reference_mode、preserve_items、acknowledge_limits，明确采用 |

预览独立持久化，不自动加入任务；版本变化、新预览取代、重复／跨任务／并发采用、相同原文重复加入均拒绝。采用前核对原文校验值；task 与预览状态原子提交。原文写入先于数据库提交，提交失败可能留下安全原文审计文件，但不会部分加入材料或错误标为已采用；后续不会自动引用该文件。交付报告增加已加入参考摘要和参考方式。

尚未提交的浏览器参考方式／勾选跨页保留，不跨刷新持久化。未保存选择会阻止其他修改；采用失败保留选择并显示错误。预览本身在重启后可读取，旧修订不会恢复有效采用许可。
