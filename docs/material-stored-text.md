# 保存的材料文字按页核对（0.325）

材料区主动选择“核对保存的材料文字”，再分别读取保存正文和原解析片段。来源明确区分文件文字提取、用户补充文字、人工核对图像候选；原解析片段始终标为未确认，不因为后来补充正文而变成正式采用正文。保留原覆盖说明和图像未知项，不自动采用、发送或重新确认。

每个字段完整范围最多2MB UTF8，每页4000 Unicode码点，支持首页/前后/末页。保留CRLF及emoji，空、缺失、非文字、编码坏或超限明确区分；超限不截断冒充完整。浏览器核对页长度、范围及本页SHA256；完整字段摘要和来源指纹由服务端绑定，浏览器没有全部文字，不宣称独立核对了完整字段。

主界面Task GET使用独立workspace_view=compact-v2，材料text/partial_text只投影来源索引，版本/消息仍使用原索引/窗口。旧compact、recent、完整GET及写回执保持。索引不入Store，不更改模型上下文或原材料。此模式仍从SQLite读原Task，不代表SQL分页、其它数组或完整写回执均已精简。

只读POST /api/tasks/{task}/materials/{material}/stored-text/index 接收精确revision、source_sha256和source_token（兼容完整回执可先以null读取）；page另需field=text或partial_text及offset，必须有来源token。严格8KB JSON，重复键/非有限值/额外字段拒绝。指纹绑定Task、修订、材料ID、完整可读字段摘要和来源/引用/覆盖标签；追加对话允许，改变原文字/标签/修订或跨材料拒绝。来源409清旧页/索引；坏页保留上次已核对页，切任务取消请求并拒绝晚到。

读取仅核对数据库保存文字，不重新解析、读取或校验原文件；即使原文件丢失，保存记录仍可读，不能据此声称原件存在。原件检查/下载继续使用独立原件入口和原字节校验。读取不解密、不写Store、不调用模型或Dify，不改变需求、材料引用和业务确认。
