# 最终手改 DSL 的验收语义摘要

0.33.0，2026-10-12。修补验收建议只能看到最终文件 ID、节点类型和输入输出、看不到实际手改规则的问题。不是完整 DSL 业务理解或已执行验证。

有实际 DSL 引用时，仍必须先确认当前修订的保留文件并核对结构摘要。现在建议请求的 `contract.source.semantics` 从该文件提取：实际节点 ID／类型／标题／父作用域、开始变量、结束输出、回答模板、条件 cases、代码与声明变量／输出、模板、LLM 文字消息／模型参数／上下文／记忆、检索选库和策略、无认证 HTTP 的请求配置、无分组聚合候选优先级、迭代控制字段，以及实际连接句柄和已声明的部分应用特性。不会拿旧计划代替最终字段。

字段用确定性白名单提取，深复制而不改源文件。不含布局、管理凭据、加密助手密钥、知识库全文、运行结果或实际节点轨迹。平台额外节点／特性字段仅列名称，值没有发送；说明其未知并要求模型在影响预期时提出待决定事项，不能认为省略了功能。全文代码和提示词作为参考数据，不执行或采用其中改变助手契约的指令。用户直接填写在自由文本中的全部秘密无法保证识别，仍须使用无密钥内容。

未知节点拒绝生成摘要；超过 120000 UTF-8 字节拒绝，不截断代码／条件后继续。可由用户缩小参考范围或人工编写样例，当前尚无分块总结。实际 Dify 导出／手改字段不意味着分支可达、输入会触发分支或期望业务事实正确；候选仍须人工核对，再独立试跑。

运行页可展开请求前的最终字段摘要，同时明确提示代码／提示词、模型／选库／连接标识会随建议请求发送。0.32 已确认的轻量策略只允许结构来源摘要；0.33 将范围升级为 `scope_version=2`。旧启用策略缺少当前版本时，生成被阻止且不回退主模型，用户须刷新并重新确认。PATCH 必须提交 GET 实际展示的 `required_scope_version`，旧客户端确认不能被当作接受新范围。关闭路由仍须接受当前范围说明；设置本身不调用模型。

后台专项及受控页面证据见 development-status.md。没有新增真实模型调用或 Dify 写入，本次只能证明数据提取、失效门禁和提示展示，不证明模型生成质量。
