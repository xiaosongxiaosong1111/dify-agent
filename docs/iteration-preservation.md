# 单层顺序迭代的人工修改保留

版本 0.25.0，目标 Dify 1.17.1 / DSL 0.7.0。

构建页读取或上传当前 Dify 编辑草稿后，可对单层顺序迭代进行三方差异分析和保留。支持一个内部开始节点和 1—12 个顺序代码、模板或文字 LLM 节点，输出取最后一个处理节点的已声明 string／number／object 值，汇总为同类型数组。任一项失败终止整批，不展开输出。

内部执行顺序以实际连接为准，不依赖文件中节点数组、连接数组或画布位置的排列。逐项 item／index、此前内部节点输出、外部必经上游值依照原有作用域检查；容器的内部值不能被外部直接读取。允许多个顶层顺序迭代容器，各自独立核对作用域。

校验使用临时结构投影，原 DSL 不被重编译或改写。原代码、提示词、模型参数、容器大小、位置及其他平台字段进入最终合并文件；平台额外字段保留不代表它们的运行语义已验证。相同内部节点字段发生人工修改和新生成修改的冲突，仍须逐项确认 current／generated。应用合并会推进修订、使需求和配置确认失效，并要求重新确认；旧源应用不被覆盖。

## 明确限制

- 原生配置须明确 is_parallel=false、parallel_nums=1（缺省数量按顺序 1 核对）、error_handle_mode=terminated、flatten_output=false，并具备已声明输入／输出数组类型。
- 当前不接受并行保留。原生 DSL 没有 Sierra 的逐项独立性声明，不能捏造声明，也不能把并行改为顺序后算通过。可保留原文、说明条件并另行讨论。
- 内部分支／汇合、嵌套、一般循环、失败继续／跳过、文件／视觉输入及内部 LLM 会话记忆未适配。多个开始、重复连接、孤立子图、跨容器连接、作用域标记不一致都会阻止采用，不静默删除节点。
- 图解析最多 1500 个节点和 1500 条连接；仍受原 YAML 2 MB、深度和结构上限约束。
- 本机仅做结构、变量、参数和代码语法检查，不执行用户代码、不发送请求、不创建 Dify 资源、不产生模型费用。静态通过不等于实际 Dify 导入、运行或客户业务验收。
