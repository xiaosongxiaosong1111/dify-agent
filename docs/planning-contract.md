# 模型流程规划、修复与停止契约

版本：本机工作台 0.4.0；更新日期：2026-10-09。适配 Dify 1.17.1／DSL 0.7.0。

## 适用范围

仅约束 `POST /tasks/{id}/plan/generate` 的一次模型流程规划。需求对话、模型连接探测、真实 Dify 导入和运行不包含在此次费用与重试累计内。此实现不代表完整任务预算、供应商账单硬上限或 Dify 运行故障自动修复。

生成前必须具备明确的八项需求、受支持的应用类型、可读取且采用借鉴模式的参考，以及模型输入／输出估算单价。严格复现和保留指定部分尚未实现，明确阻止生成。借鉴资料每份前 12000 字、合计最多 24000 字会进入规划上下文，截断显式标记。

## 修复规则

- 确定性补齐固定契约版本、明确的 required 布尔值、Python 语言标识和已证明的字符串条件类型。
- 允许有限的 JSON 格式修复与 Python 语法修复；代码不在本机执行。JavaScript 语法自动修复尚未支持。
- Python 修复必须保留节点身份／类型、连线、非代码配置、变量绑定，以及名字、数字、字符串和运算符序列；保护检查失败即停止。这不能证明业务语义完全等价，最终候选仍需用户确认。
- 缺资源、不支持节点、业务分支不明确等问题停止并要求决策，不自动改方案或删除功能。
- `max_retries` 为修复轮数，0 关闭自动重试；最多请求次数为修复轮数加 1。连续两次相同错误且没有进展则停止。

## 时间、费用与暂停

`max_minutes` 限制本次规划耗时，网络请求和静态验证均计入；`max_cost_usd` 为本次规划的 USD 估算上限。每次派发前按文本 UTF-8 字节数、消息余量和 6000 输出 tokens 预留费用，超限则不派发。此预留是保守估算，无法保证供应商实际账单不超限。

按供应商返回用量与用户登记的单价计算费用，缓存命中在可识别时计入；推理 tokens 不重复计费。供应商不返回有效用量、请求结果未知或缓存写入费用无法计算时，保留预留并明确标为未知，不按零收费处理，也不继续盲目修复。

暂停阻止后续调用，不承诺取消已经派发的供应商请求。暂停后迟到的结果不会应用；最后候选和诊断保留供复核。时间、费用、无进展或需要更改方案而停止时，原方案、修订和确认保持不变，任务标为暂停。

## 记录与恢复

`GET /tasks/{id}/planning` 返回当前修订及持久化 `runs`。记录包含请求修订、结果修订、模型、单价与限制快照、每次调用状态／用量／费用依据、诊断、修复记录、停止原因及最后候选。响应摘录最多保留 16000 字，不能视为完整响应。候选为最终建议，不等于配置已确认、已导入或已运行。

有效候选和成功记录原子写入同一任务，推进修订并要求确认配置。活动规划期间禁止修改相关任务和供应商连接。服务重启把未完成规划标为中断、暂停并保留未知费用预留，不自动重复请求。

## 已有验证

后台使用隔离响应验证修复、无进展、时间／费用停止、并发变更、暂停和重启恢复。独立 QA 浏览器验证费用缺失门禁、单价保存、跨页面暂停和候选显示。真实 DeepSeek 技术示例最新一次规划为 2417 tokens，一次请求通过，按登记峰值价估算 USD 0.0014838。该示例仍仅完成静态 DSL 编译，未实际导入或运行 Dify。
