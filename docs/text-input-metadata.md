输入按目标Dify／Python Unicode字符计数，不按UTF-8字节截断，也不是可见字形计数。必填只处理缺失／null，不代表文字非空，业务非空或内容规则须另明确。

页面输入只解析可无损的非负整数及明确null；空白、负数、小数、超安全范围数字保持原文待校验。用户主动选择不限才设null，明确恢复兼容默认才删除字段；0不被改成null，类型切换保留原值和连接。
