# 单层容器内文字分类（0.69）

迭代／循环的明确内部 DAG 可使用文字问题分类，为每个类别声明实际出口，全部分支汇入共同结果后继续原迭代输出或循环保护。分类不能放进仅按节点数组顺序执行的隐式顺序体；缺入口、缺类别出口、兄弟分支引用、外泄内部变量或未知设置拒绝，不自动补分支或改为默认路径。

逐项文字输入、循环中的文字状态或全路径上游文字来源需明确声明。分类模型可完整独立配置或继承任务模型，参数卡与分类卡都覆盖单层内部节点；类别说明、顺序、标签、指令和未匹配首项规则保持原契约。内部分类不读取 Chatflow 对话历史，不能靠共享历史关联批次项目。循环仍保留停止、最大次数、进度和更新保护；并行迭代仍须逐项独立性及并发／费用确认，不取消已派发项。

实际 DSL 中内部分类及其出口、模型、规则和布局可在原容器作用域内静态核对并保留，不移出容器、不重编译文件。若内部分类实际带有记忆设置，明确拒绝，不能删除设置后宣称保留。单层每体1—12节点、最多48条内部边，复杂嵌套、任意工具和文件分类仍未适配。

这是生成、配置和手改保留能力，开发验证使用隔离文字分类图、schema／作用域检查和受控界面；没有调用真实分类模型或创建／运行新的 Dify 应用，分类质量及各业务分支的实际运行仍待具体资源许可后验证。范围没有新增发送字段，沿用已说明的计划／最终语义范围，不复用已消耗的真实调用授权。
