# Sierra 验收建议模型路由

0.32.0，2026-10-12。对应多模型优化的首批功能，不代表通用多 Agent 协作已经完成。

任务面板展开“验收建议模型路由”，主动选择已有、用途为“轻量”、有密钥的服务；先核对型号、参考单价及数据范围，写明原因并确认。设置本身只保存本地策略，不测试连接、不请求模型、不修改 Dify 或业务修订。随后仍需在运行页主动请求验收样例建议。默认使用任务指定主模型。

仅 `kind=cases` 使用这项策略；访谈、流程、配置、冲突和覆盖检查继续使用任务主模型。请求包含当前需求、应用配置、入口输出／节点结构、已有样例和覆盖条目。Workflow／Agent 计划原文可能含代码、提示词及模型／选库标识；0.33.0 起已确认保留 DSL 发送明确字段摘要，包括实际条件／代码／提示词／模型和选库标识／连接；未知字段只列名称，仍非完整业务理解。旧启用策略必须接受扩大范围后才能派发。不会读取加密助手密钥、管理密码或知识库全文注入提示。用户不得在需求、代码或样例中直接填写密钥。

角色“轻量”不保证更低单价、更少 tokens 或生成质量。选择低价模型可能降低费用，但输入内容没有因此缩短。用量按实际所选服务和派发时价格计入同一任务累计账本；失败不自动换主模型，不自动升级、双模型复核或试跑。原有结构修复次数／时间限制仍适用，修复也调用同一服务并计费。建议需人工复核；采纳和试跑是独立动作。

策略有独立版本及确认历史。服务地址、型号、密钥、用途、单价或能力记录变化后，路由阻止派发，必须刷新、重新核对确认；服务缺失时不会回退。使用中的服务不能删除，存在未结算调用时不能改写或删除其配置。策略只能在任务空闲时修改，过期任务／策略版本拒绝。关闭时清空选择指针，保留历史和用量。

运行页展示下一次建议的模型；新候选记录实际生成模型、规划操作 ID、路由用途和策略版本。随后切换路由不会更改旧候选来源或让有效候选凭空失效。历史候选无来源字段时明确显示未知。浏览器路由草稿跨页面保留，阻止其他变更；保存失败保留草稿，撤销或成功保存才清除。

接口：`GET/PATCH /api/tasks/{id}/assistant-routing`，PATCH 必须包含当前业务 `revision`、独立 `policy_revision`、GET 展示的 `required_scope_version` 对应 `scope_version`（目前 2）、启用状态、选中服务的 `provider_token`、范围确认及原因。公开快照哈希不包含明文密钥；原始凭据从不进入浏览器。

验证记录见 development-status.md。当前没有新增真实供应商调用；多模型生成质量、价格变化和客户业务尚需另行验收。

## 0.37.0 循环状态范围

最终受保护循环的验收摘要新增状态声明／初始值、停止条件和赋值绑定。范围升级scope_version=3，旧启用轻量策略必须核对新的scope_note并提交required_scope_version=3；不沿用版本2确认，不自动换主模型。数据只来自已确认最终文件，无实际运行状态或知识库全文，不调用生成代码。

## 0.39 HTTP 执行策略范围

最终保留文件的HTTP证书校验／完整节点重试设置纳入验收语义摘要；实际超时已经包含，现明确字段含义。轻量范围版本升至4，旧启用策略需重新确认，新范围未实际发给模型。见 http-execution-settings.md。

## 0.41 认证引用范围

最终DSL验收摘要增加HTTP授权符号引用及所用空秘密变量名称／用途／未验证就绪标识，不包含变量值；范围升级scope5，旧启用策略须重新确认，没有真实模型派发。连接倒计时仅作显示，不进入环境确认快照，避免时间流逝使方案无故失效；真正环境元数据变化仍失效。
