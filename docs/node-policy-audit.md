# 最终成果节点设置总览

0.142在运行页新增“最终成果的节点执行设置”，用户主动读取一次全部节点中的共用执行设置及待决定问题。与未单独部署的0.141策略门禁一起发布。它不调用模型、读取／解密环境凭据、写入Task／预算、请求Dify或自动改策略，也不是试跑授权。

## 来源与范围

GET /api/tasks/{id}/node-policy-audit?revision=当前修订。只读当前最终成果（不悄悄改用旧计划或草稿），文件上限2MB、节点1—1000，不能截断后报完整。读取前后核对任务修订、成果路径和实际字节，结果带最终文本SHA256、完整节点与问题计数，响应no-store。文件或修订变化时不显示旧结果。

每行仅有节点序号／类型、JSON位置、重试启用状态、是否明确填写共用设置及静态问题；不返回节点原始ID／标题、代码／提示词／客户输入、异常默认值或凭据。HTTP由原有专用规则检查，已支持重试继续允许；文档提取检查其专属版本／解析限制，其余使用共用执行策略规则。未知节点类型不回显原文，本报告不证明该节点已兼容。

verification=local_execution_policy_only；platform_checked、business_verified、credentials_decrypted、network_requested、run_authorized均false。不提供overall valid／can_start，零问题仅表示本次没有发现这些执行设置问题，不能当完整节点兼容、费用上限或业务验收。

## 使用方式

一次展示全部节点及所有待决定项，说明保留未适配策略所需人工验证、关闭重试对恢复和潜在重复调用的影响，以及移除异常默认可能使整体失败。具体费用未知，供应商／解析器内部行为及容器调用数仍需另核对。用户决定方案后按原编辑／保存／确认流程处理，本报告没有自动关闭／修改／运行按钮。

实际保留与最终派发门禁也已改为汇集所有共用策略错误，给出各节点JSON位置，避免修完一个才看到下一个；结构无效则检查未完成，不把部分结果算成功。

页面只在用户点击时GET读取，按Task／revision／成果变化清旧结果；拒绝错归属／修订／计数／路径／验证等级或伪运行权限回执。读取失败显示未知，原成功清除，不自动回退。带文件入口的成果也可查看，无需先接通文件上传或设置环境。
