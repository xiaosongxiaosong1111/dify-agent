## 自动规划失败与恢复

这次真实自动规划没有返回可用正文，执行器暂停并保留失败记录；原实现未在这种解析失败下保存响应用量，因此该次用量仍未知，不能补记为 0。估算预留 USD 0.0093351 不是实际费用。

为隔离检索适配验证，开发者按已明确的技术规则、实际知识库和检索策略人工制定方案，并通过与正常用户相同的保存／确认／构建接口继续。没有追加规划调用，也没有把方案标成模型生成。该记录证明原生检索编译与运行，**不能证明本次知识方案的自动模型规划成功**。

已修复供应商适配：未来收到用量但正文缺失或响应结构不兼容时，保留允许的 token 字段及可识别的 `finish_reason`；规划执行器按可用用量计估算，否则仍保留未知预留。空正文不会当成功，不自动重复派发。受控测试覆盖 OpenAI 兼容／Anthropic 无正文、响应形状异常、敏感字段过滤及规划失败计费；不能倒推恢复此次已丢失的数据。

## 用量与限制

两次实际运行共 11438 tokens（输入 11230、输出 208），按登记峰值价格保守估算 USD 0.0036186。加上上述失败规划的未知预留，登记估算合计 USD 0.0129537，不能当作账单或项目总费用。Dify 插件返回价格 0 不代表免费。经济关键词索引未新增 embedding／reranker 调用。

原生 Agent 可能增加工具选择和检索后的模型轮次，输入中还包含工具说明，因此不能把它的费用或行为等同于固定 Chatflow。仅在这两个真实样例中证明发生检索，**不能承诺所有问题都会检索**。有“每轮先检索”和确定性空结果分支需求时，应向用户说明差异，建议 Chatflow，但由用户决定类型。

高质量索引、reranker、固定查询、阈值、元数据过滤、多知识集实际检索、连续会话和自主业务工具尚未全量验证。未支持的配置明确阻止构建，不能省略后宣布完成。
