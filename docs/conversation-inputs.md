# Chatflow 原参数自由续聊

0.135已部署。仅对用户明确选择的当前可信成功自由试跑来源，允许自定义初始参数完全不变、query改变后继续同一会话；不是动态更新参数、会话分叉或业务正确证明。

来源须属于当前Task／修订／环境ID及地址版本／App／最终成果，原记录为成功自由运行，实际CID、原输入摘要和凭据版本与私有绑定一致。旧记录缺绑定、成果／目标／凭据改变时，在预算、待执行与派发之前拒绝，不自动换新会话。重新登记同一Key也会改变随机密文版本；console登录刷新不因本功能改动serviceKey。

每次带自定义入口的Chatflow运行，从同一service密文行读取并解密一次，形成仅限原Env的内存ServiceSnapshot。DifyClient本次及固定多轮使用该快照，不在中途切换新Key，不读取管理或知识库凭据。密钥不写新对象、Task或日志。成功自由运行的原输入摘要、实际CID、目标／成果与随机密文摘要只在私有conversation_input_binding对象中，与Task成功状态原子提交，不进入Task／导出／模型上下文。随机密文摘要不是认证凭据或身份认证；不含原输入或答案。失败／未知不产生可复用成功绑定。

参数须完整一致，包括省略／null；变化、缺失、错误类型、额外字段均拒绝，不继承、补默认或忽略。手填CID不能代替可信来源。返回CID不同时保留实际响应但标未知，不按原会话成功或盲目重跑。固定多轮仍先检查所有轮次，不作为自由会话来源。

选来源不自动改输入。参数准备卡从最终成果核对声明，拒绝原记录的未声明字段；先预览用原值替换全部本次自定义参数、同名覆盖、额外字段移除和完整新JSON。再次确认才改本机JSON，保留当前query，不复制旧问题或CID、不保存Task或运行。手填CID须主动清除；未完成JSON保持；输入／来源／成果／修订改变使旧预览失效。无自定义入口则不显示，复制参数不等于来源可派发许可。

需要改变初始参数时，可明确选择新会话，保留当前输入从新CID开始，旧会话不被取消或还原；需要保留历史又改变业务状态时，应另行确认conversation状态等设计。不会自动开启LLM记忆，能否读取前文仍须按确认配置实际验证。

验证：20新增、94新旧对话及本机检查相关通过16.43秒；8浏览器／视觉全夹具、真实写0、原Task不变。包括目标／地址／成果／凭据／回执／输入变化、损坏索引、原子提交、实际Key与同一密文捕获、运行中Key变化、多轮Key固定、仅解密serviceKey和CID未知保护。构建主502.55KB既有体积提示、准备卡3.60KB按需。完整2704项通过286.18秒；规划契约随后更新并49相关通过3.18秒，idle-owned部署／runtime核对。没有真实Dify／模型／沙箱调用，客户业务尚未验收。
