# 对象输出的本机拒绝原因

0.175实现（部署及证据见development-status）：只对原文件模型的对象输出合同拒绝生成安全说明。可区分结束字段不符、不是对象、有限JSON／编码、64KB大小、20000实例值、无损整数范围、已确认Schema规则或未知原因。规则位置必须来自原Schema已声明的验证关键字，按JSON Pointer转义；不可打印或超过1000UTF8字节的路径不显示。未知异常文字、未知输出字段名与原值不进入说明。

安全原因随原文件方案本机保存和公开历史，HTTP错误及原普通运行错误可直接看到说明；可信原运行编号保持，输出不存、不修复、不改规则或自动重跑。历史卡再次核对版本、原完整Schema文字SHA及真实规则路径；当前新Schema不能代替旧来源。节点失败原因和业务验收另行处理，不因这份本机说明自动放宽要求。旧记录没有细分说明时不从当前规则重算。

同批将平面字段表上限对齐后端每个对象最多50属性；旧100行的UI上限会准备出后台拒绝的Schema，现不再提供第51行，不截断已有计划／Schema。高级嵌套与完整规则仍须用户明确。
