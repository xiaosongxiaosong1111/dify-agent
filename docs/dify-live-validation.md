## 首次失败及修复

首次运行在 code 节点失败，实际 Console 记录显示 Sandbox 返回 401。读取容器配置，仅比较内部认证 Key 是否一致而不输出内容，确认 API 的 CODE_EXECUTION_API_KEY 与 Sandbox 的 API_KEY 不同。将前者对齐 docker/.env 中 SANDBOX_API_KEY，并重建相关服务。未修改 DSL；同一应用上的样例重跑通过。原失败记录仍保留。

运行未成功时工作台保留 Dify 已返回的结果和运行 ID；公共错误不附带响应正文。远程状态尚未结束或未知时禁止盲目重跑。导出交付说明按当前修订与环境分别描述静态校验、真实导入和规则通过。
