# 试跑数字草稿

按最终成果填写输入时，数字框使用独立原文草稿。完整JSON保持原值；严格核对一个完整JSON数字及浏览器往返数值意义后，只有明确点击“将…数字填入本次输入”才更新。普通有限小数、负数、指数和明确0保持数字类型。

超出安全整数、精细小数舍入、溢出、非零下溢、空白、未完成输入、其他JSON类型或额外字段不会自动改成0/null/字符串。原文保留，可修正或撤销。任何数字草稿未处理时，本机检查及根自由试跑入口拒绝继续；已保存样例入口仍使用其确认输入。多数字草稿逐项跟踪。完整JSON、Task修订、成果来源变化或主动重读入口会清除旧数字草稿，不回填旧来源。独立草稿不持久化。

共用此表单的人工运行资源准备入口同步接收待处理状态，并清除原方案批准；该能力原本仅支持文字入口，此处没有扩大真实人工运行能力。数字之外的原文入口范围不由此宣称已审查。
