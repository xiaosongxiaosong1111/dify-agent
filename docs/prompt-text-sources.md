# 提示词上游文字引用

0.171：大模型提示词卡可明确选择上游文字，向当前节点user提示词末尾追加Dify引用；原文、系统规则、模型、其它节点和连接保持，不自动保存或调用模型。

候选按当前草稿所有路径上游计算：明确必填或有文字默认值的开始文字／段落／选项，单文件提取text、上游LLM.text、模板output和代码中明确string输出。单层容器还可列已到达的正文文字及明确array[string]的iteration.item／循环string状态。汇合点的单分支节点、未知路径、循环图、重复节点、不安全引用字符均不作为候选。不读取源数据，不从列表／对象／文件或数值推断文字，也不展开结构化字段。高级或未列来源仍须按完整JSON及后台规则检查。

目标user不是文字时禁止追加，不用空串覆盖。候选是声明及路径辅助，不证明输入有真实业务值、节点执行成功、模型上下文足够或内容出站已授权；保存、确认、模型费用与试跑门禁保持。实际业务与模型支持需验证。本批9项来源函数、7GUI以及浏览器真实草稿编译／原生保留通过，不等于Dify实际运行。
