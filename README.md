# Sierra 本机工作台

Sierra 是一个本机运行的 Dify 应用搭建工作台。当前适配目标为 Dify **1.17.1**，App DSL **0.7.0**。它提供任务与版本保存、需求整理、模型服务配置、材料解析、基础 Workflow / Chatflow DSL 生成和静态检查，并包含新建应用导入与运行适配入口。

## 快速启动

Windows 首次使用时，在项目目录运行 `setup.ps1`。它会检查 Python 与 Node.js 版本，在项目内创建或复用 `.venv`、安装 Python 依赖、安装前端依赖并构建页面。脚本不会修改全局 Python 或 Node 环境。Node.js 需为 20.19 或更高版本，Python 需为 3.10 或更高版本。

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

然后运行 `start.ps1`，或双击 `start.cmd`。后台通过 `127.0.0.1:8765` 提供页面和 API；在浏览器访问 <http://127.0.0.1:8765/>。健康检查地址为 <http://127.0.0.1:8765/api/health>。运行 `stop.ps1` 可停止本项目启动的后台。

服务日志保存在 `data/server.out.log` 和 `data/server.err.log`，PID 保存在 `data/server.pid`。应用数据和加密凭据位于 `data/`；请勿提交或分享该目录内容。

## 初次配置

打开页面后，在“模型接入”中选择服务商、模型型号并输入自己的 API Key；自定义服务地址等位于高级设置。文本和 JSON 测试的等待、成功或失败直接显示在对应模型下方。搭建助手使用的模型与生成到 Dify DSL 中的模型配置是两项设置。需要真实导入或运行时，还需配置目标 Dify 环境及对应管理、运行或知识库凭据；这些凭据类型不能互相替代。没有用户模型 Key 或 Dify 实例时，外部模型调用、真实导入和真实运行尚未验证。
